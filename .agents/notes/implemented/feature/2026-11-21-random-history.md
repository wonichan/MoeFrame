# Agent Note: 随机播放的记账只在成功显示时提交

Status: implemented

## Problem

[工单 12](../../../../.scratch/v1-exe/issues/12-random-history.md) 要在工单 11 的顺序轮播上加随机防重复与实际历史回看：随机新选择只来自本轮未看路径、看完一轮才开新一轮且避开上一轮最后一张、上一张按实际历史回看且不扰动本轮进度。父规格 §3 与 ADR-0002 的硬约束是：本轮进度与历史是两份互不代用的状态，且只有成功显示才允许提交当前图片、本轮进度与历史变化，候选计算与预加载不得提前记账。若把随机状态散进导航逻辑或让备袋顺手清进度，这些不变量无法在接缝上验证，失败与预加载还会污染记账。

## Decision

- 播放序列同时持有三份状态：本轮进度（本轮成功显示过的路径集合）、历史（实际成功显示顺序，上限 512 条）、洗牌袋（本轮未看路径的随机候选顺序）。成功显示的落位分两条：新鲜选择走 `record_fresh` 记账（进度、历史、当前图一并提交），历史往返走 `land_history` 只动历史游标。回看中下一张先沿历史返回最新端，回到最新端才继续抽袋。
- 新一轮分两步开启：未看耗尽时只备袋并标记待提交，当前图暂不入袋；本轮进度等本轮首张成功显示时才清，上一轮最后一张随即放回袋中。备袋阶段候选若全失败，旧一轮进度原样保留。失败路径留在袋中仍属未看，失败不记账无需补偿逻辑。
- 随机性经 `RandomSource` 接缝注入：播放序列与行为核心只依赖 `next_below(bound)`；宿主用 rand（需求文档 §8.3 类别）的线程随机源实现，测试用确定性实现（恒等洗牌/恒零）。
- 随机模式的首次扫描首图也是新选择，候选来自洗牌袋而非自然序；顺序模式首图仍按自然序。恢复场景的首图例外（恢复图不算新选择）归工单 13。
- 模式切换只换候选来源并发保存效果，不动计时截止时刻；两种模式下成功显示都记入本轮进度与历史，切到随机后已看过的图不会被当作未看重抽。配置新增 `set_playback_mode`，与既有单字段保存一并抽出共用 `update` 骨架。
- `Playlist::restored` 是工单 13 的构造接缝，本票仅用它验证「历史中已不在图库的路径自动跳过」；跨启动持久化与恢复本身不在本票，洗牌袋从不保存（ADR-0002）。

## Alternatives considered

- **备袋时立即清本轮进度** — 实现更简单；但候选计算与预加载都会触发备袋，清进度会让仍在显示的图在候选全失败后被误判为未看，违反父规格 §3，因此拒绝，改为待提交标记。
- **播放序列内直接调用 rand 全局随机** — 少一个接缝类型；但行为测试将无法控制随机性，只能断言整段排列或随机调用次数，违反父规格 Testing Decisions，因此拒绝。
- **顺序模式不记本轮进度与历史** — 随机才需要这两份状态；但用户随时可能切到随机，切前看过的图若未记账会被当作未看重抽，因此两种模式统一记账。

## Testing

- 全量测试 101 项全绿（本票新增：播放序列 8 项、行为核心 6 项、配置 1 项）。播放序列覆盖：轮内只抽未看、新一轮避让上一轮最后一张、两图交替、单图无候选、候选与预加载不记账、新一轮备袋不提前提交、历史回看与返回最新、已删路径跳过、512 条上限；行为核心覆盖：随机抽袋、回看往返、失败不记账、切模式保存且不重置计时、随机首图来自袋序（恒零洗牌）、单图随机不导航。
- Windows 目标 `cargo check --all-targets`、clippy 通过（仅余工单 09 验证程序的 3 个既有警告）；`cargo fmt` 已应用。
- 双轴审查（基线 `db8b77b`）：Spec 轴两项发现均已修正并补测试——随机首图绕过洗牌袋、新一轮在备袋时提前清进度。Standards 轴无硬违规；判断项处置：`peek_next` 更名为 `preload_target`（原名暗示纯读、实际会备袋），配置三个单字段保存抽出共用骨架；保留两项并记理由——`Playlist::restored` 是工单 13 的既定接缝且本票验收第 5 条需要它，`FrameCore::new` 四个参数均为明确类型且同源于配置结构，包一层结构体的收益不足。
- 未验证：菜单「播放模式」勾选与保存的真机表现、随机轮播与历史回看的实际操作手感，需 Windows 实机记录；与工单 10/11 的实机清单合并确认，本票因此转 `needs-info`，不标 resolved。

## Consequences

- 工单 13 可直接在 `restored` 接缝上接入跨启动恢复：保存本轮进度与历史路径（不含洗牌袋），恢复图作为防重复例外单独处理。
- 行为核心的导航从此分新鲜/回看/返回三种落位，后续工单 14（切换动画）与工单 15（点击手势）复用同一套导航意图时须保持落位语义，不得把历史往返当作新鲜选择记账。

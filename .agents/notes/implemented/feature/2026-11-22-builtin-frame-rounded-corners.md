# Agent Note: 内置画框圆角——三边界圆弧、接缝出数据、宿主沿弧作画

Status: implemented

## Problem

内置画框的三个角边界（窗口外沿、框体内沿、卡纸内沿）全是直角：
截面明暗重做之后边部质感已经立体，角部仍是生硬的直角拼接，整框
看起来死板，与真实木质画框角部打磨圆润的观感不符。用户经
grilling 定案圆角口径，并以 CSS 原型四变体对比选定半径方案 C
（外 20 / 框体内沿 10 / 卡纸内沿 12 逻辑 px），spec 落在
`.scratch/rounded-corners/spec.md`，工单为圆角工单 01。

## Decision

只动内置画框绘制层，几何、命中、解码、配置零改动：

- 布局接缝（frame_layout）扩数据，宿主不做半径推导：
  `BuiltinShading` 新增 `corners: FrameCorners`——三个角边界各
  一份 `CornerBoundary { radius, centers[4] }`（圆心顺序左上、
  右上、右下、左下）。半径 = min(定值，相邻带厚，窗口半宽 /
  半高，本边界矩形半宽 / 半高)：外沿的相邻带是整幅单边内距
  （框宽 0 时即卡纸带），框体内沿的相邻带是框带，画面边缘的
  相邻带是卡纸带（卡纸 0 时是框带，此时画面边缘由框体内沿
  呈现、半径仍取 12 定值）。框宽为 0 时框体内沿边界缺席。
- 弧段配套同出自接缝：造型线各带自己的圆角半径（按落笔矩形
  在框带中的分位在外沿与框体内沿半径之间线性插值）；两道
  FadeBand 各带边界半径（框影 = 框体内沿、画面影 = 画面
  边缘），宿主描边环逐层内收时半径同步递减；卡纸斜切面带
  外沿半径（= 画面边缘半径 + 切面宽）。
- 宿主（frame_paint）沿数据作画：框体基色以圆角整幅铺底
  （弧外透出桌面）；截面条带只画直边段（上 / 下边避开外沿
  切点，左 / 右边避开两条弧的切点），四角由 `paint_corner_arcs`
  以外沿圆心逐圈描弧补齐（归属与直边铺法一致：上边带管上
  两角、下边带管下两角，档位色与直边段同源）；木纹细纹在直
  边段钳制落笔、不戳出圆弧，四角另以同分布的短弧细纹沿弧
  走向；造型线、两道影、内沿细线全部以接缝半径描边。
- 内角覆盖式：插画的解码目标与落笔矩形不变、纹理不裁剪；
  插画落笔后由 `paint_image_corner_patches` 把四角在弧外的
  方形角尖盖回应有层——卡纸在场时是卡纸面扇 + 斜切面环扇，
  卡纸缺席时是框带收尾色（归属边内唇档位）。斜切面条带同
  步只画直边段，角部环扇由修补补齐；空状态无插画可压，修
  补只补条带缺口、颜色无痕。egui 的 CornerRadius 是 u8 口径
  （f32 传入自动取整），亚像素半径在落笔时取整，属平台口径。

## Testing

- 布局接缝数据断言（tests/frame_layout.rs 新增 4 个）：默认
  内距下三边界半径 20 / 10 / 12 与四角圆心精确值；卡纸 0 /
  框宽 0 的退化（画面边缘 12、外沿被卡纸带夹紧为 18、框体
  内沿缺席）；带厚小于定值（框 4 + 卡纸 2 → 6 / 4 / 2）与
  极小窗口（半高夹紧外沿、退化画面半径归 0）；弧段配套
  （造型线插值半径、影带半径、斜切面外沿半径及窄卡纸夹紧）。
  既有 21 个测试一字未改、全绿（直边口径不变的钉子）。
- 本 VM 无 Linux GUI 构建条件：测试在刮擦副本（剥 rfd /
  tray-icon、启用 wayland/x11、仅留 decode-validation bin）
  上跑 `cargo test --all-targets`，全量 296 passed / 0 failed
  （基线 292 + 新增 4）；Windows 目标在本 worktree 直跑
  `cargo check --all-targets`、`cargo clippy --all-targets --
  -D warnings`、`cargo fmt --check` 全绿。check.sh 的 test
  一项以刮擦副本结果代偿，真机由用户跑清单「圆角」一节验收。

## Alternatives considered

- 宿主侧自行由层矩形推导半径：违反 spec「布局接缝出数据、
  宿主不推导」的定案，且夹紧规则会散落两处，弃。
- 角部截面用整幅网格 / 多边形镶嵌带一次成型：egui 无圆角
  裁剪，网格化与现有条带口径是两套绘制模型，改动面远超本
  票；逐圈描弧与条带同构（同分位、同档位色），弃网格。
- 插画纹理按圆角裁剪：spec 定案覆盖式（绝不裁切），且 egui
  纹理无圆角裁剪原语，弃。

## Consequences

- 内置画框三边界成圆角，外角透出桌面（窗口本就透明创建，
  与异形相框同一底子）；极简与自定义相框图路径零触碰，
  paint_plan 结构不变，圆角只存在于 builtin_shading 的数据
  里、只在内置臂被消费。
- 半径是与 PROFILE_STOPS 同级的固定常量：真机观感不合意
  时改 frame_layout 的三个半径常量即可，不动配置与设置面。
- 文档同步：REQUIREMENTS.md（仓库外）FR-311 补圆角口径、
  FR-312 补「内沿圆角覆盖角部不在裁切之列」；README「外观
  （V2）」内置画框条目补圆角一句；真机清单尾部新增「圆角」
  独立一节（四验点，既有 27 项一字未动）。

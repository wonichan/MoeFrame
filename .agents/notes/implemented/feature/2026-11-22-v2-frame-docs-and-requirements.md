# Agent Note: V2 相框外观——需求条款落地与文档收尾

Status: implemented

## Problem

V2 相框外观工单 01–04 全部落地后，需求口径还停在 V1：需求文档
FR-309 仍写着「禁止相框式设计」，与已发布的默认内置画框行为
正面矛盾；spec 定案要求 V2 生效时把 FR-309 改写并新增 FR-31x
外观条款组，时机一直压到专题收尾。另有两处文档缺口：README
没有外观说明，用户无从知道自定义相框图的契约；四张工单各自
把真机待核项留在自己的 Comments 里，没有一份可一次跑完的
合并清单。另外，工单 02 的阴影实现与 spec 原文存在一处已知
偏差（见 Decision），需求条款若照抄 spec 措辞就会写下实现
做不到的承诺。

## Decision

- 需求文档（`~/workspace/moe-frame/REQUIREMENTS.md`，仓库外、
  不在 git 管理下，版本升至 v0.2）：FR-309 改写为「默认相框式
  外观、极简为可选」，原窄边框口径限定只对 V1 与极简外观
  成立；§5.3 表内新增 FR-310～315 条款组，逐条对应已发布
  行为——外观三选一与默认内置（310）、内置三层 / 四预设 /
  双滑杆（311）、高度 = 外框总高度与内距口径（312）、内置软
  阴影（313）、相框图契约（314：PNG + 中心透明矩形洞、自动
  检测、九宫格、框厚等比、只存路径）、回退与异形（315）。
  编号经核对无冲突：§5.3 原有编号止于 FR-309。
- FR-313 按已发布行为写，不照抄 spec：spec 原文是「窗口外侧
  多层半透明扩散」，但窗口尺寸即外框尺寸、窗口外没有可绘制
  像素，工单 02 落地为框体外沿内侧的扩散带（取舍见
  [内置画框笔记](2026-11-22-builtin-frame.md)）。需求表后附
  一段说明点破这处差异，工单 05 的 Comments 同步记录；真机
  观感不接受时按既有口径回议 spec，不在文档层掩盖。
- README 新增「外观（V2）」节：三种模式、高度口径与不裁切
  铁律、自定义相框图契约一段（PNG + 中心透明矩形洞、自动
  检测、九宫格不变形、只存路径、失效回退胡桃木并在设置窗
  显示原因），不改动其它章节。
- 仓库根目录新增 `real-machine-check-v2-frame.md`：把工单
  01–04 的真机待核项合并为一份可一次跑完的清单（沿用
  `real-machine-check-10-21.md` 的体例），含工单 01 的资源
  复测（`scripts/measure-release.ps1`，稳态工作集 ≤80MB、
  冷启动对照 ~0.3s 基线）与工单 02 的阴影观感判定项。所有
  条目初始未勾；四票在用户跑完清单前保持 needs-info，本票
  对应验收条不勾、只记「清单就绪、待用户执行」。
- GLOSSARY 一致性核对（不改动）：外观 / 画框 / 框体 / 卡纸 /
  内距 / 相框图 / 异形相框七个词条逐条对照已发布行为——三
  模式与默认内置、四边独立内距、卡纸可为 0、洞须包含中心、
  异形只来自自定义相框图，均与实现一致，无真冲突需修。

## Alternatives considered

- 需求文档搬进仓库一并版本管理：文档自 V1 起就在仓库外
  `~/workspace/moe-frame/` 与视觉基准同目录，工单 23 的验收
  引用也按此路径；本票只做内容对齐，迁移仓库是另一件事，
  不在本票顺手做。
- FR-313 照 spec 原文写「窗口外侧扩散」、实现差异只记在
  笔记里：需求文档是验收依据，写实现做不到的条款会让后续
  验收无所适从；按已发布行为写并在表后点破差异，验收与
  实现才对得上。
- 真机清单等用户跑完再建、一次回填结果：清单本身是用户
  执行的前提，先交付空白清单、四票状态等结果回来再回填，
  与 V1 清单的用法一致。

## Consequences

- 收益：需求、README、术语表与已发布行为四处口径一致；
  FR-309 不再与默认画框矛盾；阴影偏差在需求层显式可见，
  不会被后来的验收当成实现缺陷或文档错误来回翻。
- 代价：需求文档在仓库外、无 git 历史，本次改动只能靠本
  笔记与工单 05 的 Comments 追溯；真机清单的结果回填仍
  欠一次用户执行，工单 01–04 与本票都因此停在 needs-info。
- [相框外观提案](../../proposed/feature/2026-11-22-picture-frame-appearance.md)
  的状态本票不动：其 Acceptance criteria 含真机复核项，
  尚未全部满足，不存在可标记的完成点。

# Agent Note: 相框按当前图像比例自适应宽度

Status: implemented

## Problem

Windows 实机显示图片时，固定窗口比例下出现大块黑色留白；点击图片侧边区域还能切图，黑色区域因此成为不可见的交互区。现有 Fit/Fill 选择、手动宽高比锁定与侧边导航分别来自设置、几何和手势决定，无法满足「完整显示整张图且没有黑色背景」的现行要求。实机还暴露出相框右键菜单不弹出，以及托盘左键/右键都弹菜单、菜单动作延迟或不响应的问题。

## Decision

- 图片始终完整显示，不裁切也不留边：以用户调整的窗口高度为缩放基准，窗口宽度随当前图像源比例调整。每次成功载入图像后，宿主把源图比例交给 `GeometryMachine`；绘制使用整块相框客户区。最小窗口尺寸仍保持当前比例，恢复默认沿用当前图片比例与默认高度。
- 移除用户可选的适应/填充模式和手动宽高比锁定控件；`display.fit_mode`、`window.lock_aspect` 不再是配置字段，读取旧配置时删除这两个遗留键。内部显示数据仍按完整图像口径生成，不让旧配置重新启用裁切或留边。
- 图片单击和滚轮不切图；保留键盘左右键、相框/托盘菜单上一张与下一张，以及定时播放。双击打开当前原图的行为不变。
- 切图不播放滑动动画，加载成功后立即完成显示提交，保留核心原有的成功显示记账与持久化路径。
- 相框面板的右键菜单绑定可接收点击的 egui 响应；菜单弹出时不启动原生窗口拖动。托盘显式关闭左键弹出菜单，左键抬起只切换相框可见性、右键负责弹菜单；托盘与菜单回调通过 channel 投递事件并请求 egui 重绘，实际动作仍由宿主统一转发。
- 本决定部分取代 [设置窗显示方式](2026-11-21-settings-window.md)、[几何生命周期](2026-11-21-window-geometry.md)、[几何状态机](2026-11-21-geometry-machine.md)、[手势判定](2026-11-21-gesture-actions.md)、[滑动转场](2026-11-21-slide-transitions.md)、[设置窗会话](2026-11-21-settings-session.md)、[持久化同步](2026-11-21-config-sync.md) 和 [托盘生命周期](2026-11-21-tray-lifecycle.md) 中相应的旧行为；[ADR-0001](../../../../docs/adr/0001-defer-side-click.md) 保留历史理由，不再定义当前图片区单击行为。

## Alternatives considered

- **固定窗口并使用 Fit**：实现最直接且保证整图可见，但会继续留下黑边，与实机反馈及「没有黑色背景」要求冲突，因此不采用。
- **固定窗口并使用 Fill**：能覆盖窗口，但会裁掉源图的一部分，违反完整展示要求，因此不采用。
- **继续用图片侧边单击或滚轮导航**：能提供快捷入口，但黑色区域也会变成隐式热区，且与用户确认的导航边界冲突，因此仅保留键盘和菜单手动导航。
- **保留滑动转场**：维持原视觉效果，但不同源图比例切换时更容易暴露留白；用户确认切图瞬时完成，因此不保留。

## Testing

- `cargo test --all-targets --quiet`：Windows 本机全目标通过；包含右键菜单可弹出的 egui 合成回归、托盘左键/右键映射、图片区单击不导航、配置旧键迁移、按源图比例调整/恢复窗口尺寸等测试。
- `cargo fmt --all`：通过。
- `cargo clippy --all-targets`: 通过；仅保留本次无关的既有警告。
- `cargo build --release`: 通过。
- 待实机复测：不同宽高比图片切换时无黑边且窗口宽度随比例变化；图片单击/滚轮不切图、方向键可切图（当时验收无动画，后续见交叉淡化笔记）；相框右键菜单与失焦状态下菜单项生效；托盘左右键分别执行预期行为，托盘菜单动作及时生效。

## Consequences

- 不同宽高比图片之间切换时窗口宽度会变化；位置和用户设定高度保留，最终几何仍通过既有防抖持久化。这是消除留边并完整显示图片的直接代价。
- 旧配置里的 Fit/Fill 与宽高比锁定值被忽略并清除；恢复默认后宽度由当前图像比例推导，不再固定为 480×320。
- 内部 `DisplayMode` /显示数据管线暂时保留，避免把本次用户界面与行为调整扩展成深挖工单 07 的解码管线合流；若后续要删除内部 Fill 路径，应单独验证实验解码与显示数据边界。
- 自动化测试不能证明 Windows 原生托盘/焦点行为；发布前仍须完成上面的本机 GUI 复测。
- 后续切图行为见 [切图交叉淡化与窗口几何动画](2026-11-22-switch-animation-and-geometry.md)：本笔记「切图不播放滑动动画、加载成功立即提交显示」被 240ms 交叉淡化取代；固定高度、宽度随图比例和完整显示不变。

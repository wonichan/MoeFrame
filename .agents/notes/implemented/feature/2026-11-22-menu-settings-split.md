# Agent Note: 菜单与设置窗职责再分工：菜单只留五项，其余收进设置窗

Status: implemented

## Problem

实机使用中相框右键菜单与设置窗内容高度重复（播放模式、切换间隔、开机自启、重新扫描两处都有），菜单过长。用户 2026-11-22 决定反转分工：右键菜单只保留高频播放操作，其余功能全部收进设置窗，单一入口维护。

## Decision

- 相框右键菜单最终五项，顺序固定：上一张、下一张、暂停/播放（文案随状态）、设置、退出。删去选择文件夹、重新扫描、播放模式子菜单、切换间隔子菜单、当前图三项、开机自启勾选与全部分隔线。
- 设置窗「图库文件夹」区新增「选择文件夹…」按钮，与「重新扫描」并排一行。点击经会话 Picks::folder_pick → SessionAction::PickFolder → 宿主执行核心既有 Intent::FolderPickRequested（不新增核心意图，效果仍是 Effect::PickFolder，取消选择无状态变化）。
- 选文件夹与「重新扫描」同规否决待结算：end_frame 中 folder_pick 分支位于关闭/重扫之后、待结算结算之前，清 pending 与同帧失焦记录、草稿文字保留；选定生效后路径框由既有快照作废机制重播种。会话层两条测试钉住（跨帧待结算、同帧失焦）。
- 设置窗新增「当前图」一组（打开当前原图 / 打开所在文件夹 / 复制图片路径），仅在有图显示时渲染；三项经 Picks → SessionAction::{OpenCurrentImage, OpenCurrentFolder, CopyCurrentPath} 执行（双轴审查后由宿主内联改走统一 Picks 通道），宿主执行时按核心当前视图取图，复用既有 open_image / open::that / copy_text 口径，路径字符串与原菜单项一致。
- 设置窗尺寸高度 630 → 700 以容纳新增两组。
- 空状态提示文字改为「右键打开设置，选择图库文件夹」；核心 View::Empty 文档同步。首次启动自动弹文件夹选择器是核心 Intent::Started 驱动，不经菜单，不受影响。
- 托盘菜单不改（本就只有显隐、播放/暂停、上下张、设置、退出）。

## Alternatives considered

- 保持双份（菜单与设置窗各一份）：用户否决，重复维护且菜单过长。
- 反向分工（常用项留菜单、设置窗只留低频项）：助理曾提此案，用户明确选定本案（菜单五项清单由用户逐项点名）。
- 当前图三项在设置窗内联执行（初稿）：双轴审查指出与全窗统一的 Picks → SessionAction 模式不一致，改为统一通道。

## Testing

- 会话层新增 3 项测试：选文件夹跨帧否决待结算且保留草稿文字、同帧失焦被丢弃、当前图三点选按序产出动作。
- 全量 230 项测试通过（227 + 3）；Windows 目标 check 与 clippy 干净（仅既有 3 条校验器警告）。
- 双轴 code-review（基线 e66eeb4）：Spec 轴八条验收标准中 1–7 达标，第 8 条（本笔记与对齐记录）随本次交付补齐；Standards 轴两处硬问题（三处宿主注释与 SessionAction 顺序文档仍述旧菜单）已修，模块头否决枚举同步补选文件夹。
- 实机复测项已写入仓库根 real-machine-check-10-21.md 的「菜单与设置窗再分工复测」一节（菜单五项构成、设置窗选文件夹与当前图、否决语义），待实机回执后本专题工单转 resolved。

## Consequences

- 父规格 .scratch/v1-exe/spec.md §6 的菜单构成表述被本决定取代（正文不改写，取代关系记于本笔记与受影响工单的对齐评论：v1 工单 10/15/18/19、深挖工单 02）。
- 工单 19 的草稿作废外部来源收窄：相框菜单不再产生预设/模式/文件夹点选；作废来源为设置窗内点选与选文件夹生效后的快照顶替，机制不变。
- 设置窗成为除播放控制外全部功能的唯一入口；后续新增低频功能默认进设置窗，不再进右键菜单。

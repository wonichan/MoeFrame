# Agent Note: V2 内置画框——三层绘制、预设滑杆与自绘软阴影

Status: implemented

## Problem

工单 01 的地基（见 [外观地基](2026-11-22-appearance-foundation.md)）
落地后，内置画框模式仍是零内距占位，与极简视觉无差别。工单 02
要把内置模式做成真正的画框：三层绘制、四款框体预设、框宽/卡纸宽
双滑杆、自绘软阴影，并替换 `AppearanceMode::insets()` 的内置占位。
绘制矩形若由宿主临场计算，几何口径（画面 = 外框 − 内距）与绘制
口径会各自漂移；spec 定案以一条薄布局接缝统一产出（决策过程见
[相框外观提案](../../proposed/feature/2026-11-22-picture-frame-appearance.md)）。

## Decision

- 新增库模块 `frame_layout` 作为布局接缝：`builtin_layers`（窗口
  矩形 + 四边内距 + 框宽）产出框体 / 卡纸 / 画面三层矩形——画面
  层 = 窗口按内距内收，与几何口径同源；卡纸宽为 0 时卡纸层与
  画面层重合，三层退化为两层；`shadow_layers` 产出自绘软阴影的
  扩散层序。宿主只照单绘制，工单 03 的九宫格矩形也将落在这里。
- 内置画框参数落 `[display]` 配置域三键：`frame_preset`
  （walnut 默认 / oak / black / white）、`frame_width`（默认 14）、
  `mat_width`（默认 18），整数与浮点都收、钳制到 0..=40、非法回
  默认，与既有字段级修复同口径。`AppearanceMode::insets(frame)`
  改为按参数供给：内置单边 = 框宽 + 卡纸宽、四边相等；极简恒
  全 0；自定义仍全 0 占位待工单 03。`DisplayConfig` 与 `Config`
  因 f32 字段去掉 `Eq` 派生（只保留 `PartialEq`）。
- 持久化与设置窗沿工单 01 的宿主状态镜像模式：启动包携带初值，
  宿主持当前值；设置窗「外观」组内新增一块内置画框参数控件
  （预设单选 + 框宽 / 卡纸宽双滑杆，仅内置模式显示），点选经
  会话机新增的三个动作（预设 → 框宽 → 卡纸宽，与外观点选同规：
  同值守卫、顺序在外观之后与间隔预设之前、变体追加在枚举尾部），
  宿主执行时改值并经 config_sync 整组写回，滑杆拖动逐帧即时生效。
- 绘制在新宿主模块 `frame_paint`：框体基色按预设合成，框带内
  两道同心半透明细线冒充木纹走向，外亮内暗收倒角感；卡纸默认
  米白；内沿细线沿画面边界贴内侧画 1px 半透明暗线；纹理只落
  画面层。内置模式下面板底改透明，极简 / 自定义仍是黑底铺满。
- 阴影落在框体外沿内侧：窗口尺寸即外框尺寸（工单 01 几何
  口径），窗外没有可绘制的像素，扩散带（6 层 × 2px，黑色透明
  度 64→12 逐层递减）以逐层内侧描边画在三层之上、内沿线之下，
  只出现在内置模式。

## Testing

- 布局接缝（tests/frame_layout.rs，6 例）：三层按框宽/卡纸宽
  嵌套、卡纸 0 退化两层、两层宽度不等、框宽 0、四边内距不等时
  画面层逐边对齐几何口径、阴影层逐层严格内收且透明度递减。
- 配置（tests/config.rs 新增 6 例）：默认胡桃木与 14/18 写回、
  四预设解析与非法修复回胡桃木、宽度钳制与整数接受、非法回
  默认、整组保存往返、内置内距 = 框宽 + 卡纸宽四边相等（极简 /
  自定义全 0）。
- 同步与会话（tests/config_sync.rs 新增 1 例、tests/settings_session.rs
  新增 2 例）：启动包携带画框初值与整组写回落盘；参数点选的
  动作顺序（外观之后、间隔预设之前）与同值守卫。
- 本机验证：Linux 刮擦副本全套 256 例全过（基线 241 + 新增
  15）；Windows 目标 `cargo check --all-targets` 与
  `clippy -D warnings` 干净；`cargo fmt --check` 通过。三层
  观感、阴影效果与滑杆手感只能在用户 Windows 机上核，工单 02
  因此停在 needs-info。

## Alternatives considered

- 阴影边距并入内距（把窗口放大一圈留透明边距，在边距里画投到
  桌面的真投影）：单边内距 = 框宽 + 卡纸宽是工单票面定案，
  GLOSSARY 的内距也只指画框厚度；为阴影改几何口径会牵动工单
  01 的退化对照与解码口径，代价远大于本期收益，先以框沿内侧
  扩散带顶替，真机观感不接受再回议 spec。
- 绘制矩形由宿主按内距临场计算：省一个库模块，但绘制口径与
  几何口径从此有两份实现，spec 的布局接缝正是为防漂移而设；
  且工单 03 的九宫格矩形也要同一出处。
- 滑杆松手才落盘（拖动中只改内存值）：与工单 01「切换即落盘」
  的宿主镜像口径不一致，拖动中进程退出会丢值；整组写回是
  小文件操作，逐帧写回可接受。

## Consequences

- 收益：内置模式成为默认即见的真画框（默认胡桃木 + 米白卡纸）；
  布局接缝就位后，工单 03 只需在同一模块加九宫格函数，宿主
  绘制照单扩展；参数三键与既有配置修复 / 同步通道完全同构，
  手改配置的容错不变。
- 代价：阴影是框沿内侧的扩散带而非投在桌面上的真投影，观感
  取舍留真机判定，不接受则回议 spec 改几何口径；滑杆拖动逐帧
  写配置文件（小文件，可接受）；设置窗高度提到 830；
  `Config` / `DisplayConfig` 失去 `Eq` 派生（仓内只用 `PartialEq`
  做相等断言，无实际影响）。

# Agent Note: 内置画框观感重做——截面明暗、贴边投影与卡纸斜切面

Status: implemented

## Problem

工单 02 的内置画框首轮真机验收被用户退回：框体是平色块加两道
同心细线、卡纸是平米白、阴影是贴在框体外沿内侧的一圈灰色扩散
带——三层都在，但没有真实画框的深度线索，看起来像色块拼贴。
问题不在几何（内距、三层落点都对），在绘制模型：真实画框的
「像」来自截面明暗、相邻层之间的投影与卡纸切口，本实现三样
都没有，唯一的阴影还落在没有语义的位置（框体外沿内侧，既不
是谁投给谁的影，也衬不出层次）。

## Decision

只重做内置模式的绘制，不动几何、配置与设置口径：

- 布局接缝新增着色计划 `builtin_shading`（与 builtin_layers
  同吃窗口矩形 + 四边内距，另收框宽 / 卡纸宽）：一次产出三层
  矩形、四边截面着色（带矩形 + 明暗档位）、造型线落笔矩形、
  卡纸着色（框影 FadeBand、斜切面外沿、画面影 FadeBand），
  全部纯数据；`shadow_layers` 及其常量删除。宿主 frame_paint
  只按预设选基色并照单落笔，几何口径不漂移。
- 框带截面明暗：明暗档位 = 截面走向（外沿 0.84 → 中段隆起
  1.05 → 凹槽 0.76 → 内唇 1.10）× 方向光（光自左上：上
  1.07 > 左 1.02 > 右 0.95 > 下 0.89）。宿主把每条边沿带宽
  细分成 12 条带、按档位插值取色落笔（egui 无渐变填充原语，
  细条带是本仓可控的近似）。造型线三道（外沿压线、内唇外 3px
  凹槽、内唇亮线）以 1px 内侧描边叠在渐变上，落笔矩形由接缝
  给出，窄框（<5px）自动去掉凹槽、<2px 整体缺席。
- 木纹：胡桃木 / 原木在渐变之上叠确定性细纹——xorshift32
  固定种子、每条边 14 条沿长度方向的低透明短线，位置与明暗
  只由序号决定、逐帧不变；黑、白是漆面，不叠木纹。
- 投影改两道贴边影，删除游离扩散带：框体投在卡纸上（贴框体
  内沿、向卡纸内淡出 7px、边界透明度 58），卡纸投在画面上
  （贴画面边界向内淡出 5px、透明度 46）；宿主以逐层内收的
  描边环落笔（8 环）。两道影都在 FadeBand 口径里，深度钳到
  卡纸宽内，框宽为 0 时框影缺席（无框可投）。
- 卡纸内口斜切面：画面外扩 2px 的一圈近白色（45° 切面受光
  面），宿主以四条带落笔——空状态下画面区域保持卡纸原色，
  只露切面一圈；原有 1px 内沿压痕线保留，与斜切面共同收边。
- paint_plan 结构不动：投影只经 Builtin 分支可达，极简 /
  自定义路径逐项未改。

## Testing

- TDD（布局接缝，tests/frame_layout.rs）：先写红（接缝不存在
  编译失败），实现后转绿。新增 6 例钉住着色几何：着色计划的
  三层与 builtin_layers 逐项一致；四边矩形恰好铺满框带、方向
  光序与截面走向（内唇最亮、凹槽最暗）；造型线落点与窄框
  退化；框影 / 斜切面 / 画面影的落点与深浅次序；窄卡纸钳制
  与卡纸 0 缺席；框宽 0 无框影。旧阴影扩散层测试随
  shadow_layers 删除而移除（−1），paint_plan 的覆盖未动。
- 本机验证：Linux 刮擦副本全套 289 例全过（基线 284 − 1 +
  6）；Windows 目标 `cargo check --all-targets` 与
  `clippy -D warnings` 干净；`cargo fmt --check` 通过。
- 观感本身只能真机核：工单 02 维持 needs-info，真机清单的
  工单 02 节已把判定项换成新口径（质感判定 / 投影判定）。

## Alternatives considered

- 渐变用顶点色 mesh（egui::Mesh）：插值更平滑，但网格的 UV
  采样落在字体纹理图集上，需要额外的白色像素口径处理，本
  机无法上屏验证，出错形态是整带花屏；12 条细分条带在 14px
  框带上约 1.2px 一条，低于可辨阈值，取条带。
- 阴影边距并入几何（窗口放大一圈画真桌面投影）：工单 02 首
  轮已议过，代价不变（牵动工单 01 退化对照与解码口径），
  本期仍不取；真机若仍不接受贴边投影，再回议 spec。
- 木纹引入图片素材：spec 定案绘制层合成、不引入素材，不取。

## Consequences

- 收益：内置画框的深度线索与真实裱画同构（截面、投影、切
  口），且每条线索的几何都钉在布局接缝的测试上，后续调参
  （档位、深度、透明度）只动接缝常量与宿主色板，不散落。
- 代价：每帧绘制原语数量上升（四边各 12 条带 + 木纹 56 条
  线 + 两道影各 8 环），都是小矩形 / 线段，对本程序的帧量级
  可忽略；截面档位与方向光倍率是首轮取值，真实观感（尤其
  原木的提亮与白框的暗线对比）要等真机判定后微调。
- 工单 02 的观感验收重新打开：状态维持 needs-info，等下一
  轮真机按更新后的清单核对。

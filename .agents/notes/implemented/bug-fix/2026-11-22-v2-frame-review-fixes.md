# Agent Note: V2 相框外观评审修复——回退默认画框、布局接缝统一与生效外观一次裁决

Status: implemented

## Problem

V2 相框外观专题（工单 01–05）合并后的双轴评审无硬性规范违规，
但留下四项发现。其一是规格口径错误：自定义相框图未生效（未选
图或分析失败）时，宿主按用户**当前**的内置预设与滑杆值回退，
而 spec 定案是回退内置**默认**画框（胡桃木 + 默认宽）——用户把
内置框调成别的样子后，回退画出来的不是默认框。其二是布局接缝
分裂：九宫格布局在 frame_art 里自带一套 `[f32; 4]` 数组口径，
与 frame_layout 的内置三层是两处实现，spec 的「一个布局纯函数
统一产出」未落（工单 03 留的已知跟进项）。其三是「自定义未生效
即回退内置」这条规则在宿主生效内距、绘制计划、配置内距三处
各编码一份，改口径要三处同动。其四是 GLOSSARY 里「外框」是
框体的 Avoid 词，但代码与工单广泛用「外框尺寸 / 外框总高」指
整块窗口的外尺寸，读文档时容易与框体层混淆。

## Decision

- frame_layout 新增生效外观裁决 `effective_appearance`：吃外观
  模式、相框图是否生效、用户内置参数，一次产出 `EffectiveAppearance`
  （极简 / 内置（生效参数）/ 自定义生效）。自定义未生效 ⇒
  `Builtin(BuiltinFrame::default())`——默认值取既有默认常量
  （胡桃木、框宽 14、卡纸宽 18），不新写字面量；内置模式 ⇒
  用户参数原样。回退由此成为纯运行期裁决：已保存设置只读不改，
  相框图恢复有效后自定义无痕恢复。
- 三处消费统一到这一份结论（发现三随之关闭）：`paint_plan` 改
  吃生效外观；宿主 `effective_insets` 只在自定义生效分支换成
  分析缩放内距、其余取结论自带内距；内置绘制
  `paint_builtin_frame` 改收生效参数为入参、不再读宿主保存的
  用户参数。配置层的 `AppearanceMode::insets` 保留为模式自身
  的静态内距（结论的内距经它算出），不再单独编码回退规则。
- 九宫格布局迁入 frame_layout：`SliceRegion` 的源/目标矩形与
  洞区矩形全改与内置三层同一的 `LayoutRect`，`[f32; 4]` 数组
  口径消除；frame_art 只余分析（洞检测）与加载。宿主仅剩的
  egui/LayoutRect 转换收拢到宿主根模块一份，frame_paint 不再
  私藏转换函数。工单 03 的已知跟进项就此关闭（工单文件已追加
  记录）。
- GLOSSARY 框体条目加一行注： 「外框尺寸 / 外框总高」指整块
  窗口的外尺寸，不是框体层。仅此一行，无其它术语改动。

## Alternatives considered

- 只在宿主回退分支把参数换成默认值、不动结构：改动最小，但
  「回退即内置」仍在三处编码，且回退的绘制参数与内距可能再次
  漂移（这次评审发现的正是这种漂移的结果），不取。
- 把生效外观裁决放进 config 层：config 是配置契约层，不认识
  「相框图是否生效」这一运行期状态；放 frame_layout 与绘制
  计划同居，消费方都在同一接缝上，不取 config 方案。
- 九宫格保留在 frame_art、仅把矩形类型换成 LayoutRect：类型
  统一了，但「统一产出」仍是两个模块两套函数，spec 口径不算
  落地，不取。

## Testing

- TDD（回退口径）：先在 tests/frame_layout 写红——裁决接缝不
  存在、paint_plan 仍是旧签名，编译失败即红；实现后转绿。
  新增 3 例钉住裁决：内置模式用用户参数原样（原木 30/6，内距
  36）、自定义未生效回退默认（同组用户参数下仍为胡桃木默认，
  内距 32）、自定义生效与极简直达结论。
- 九宫格两例随迁 tests/frame_layout，断言逐项保留、四角与边的
  期望值由数组口径换算为 LayoutRect 口径（源矩形语义不变，
  目标矩形由「原点 + 尺寸」改为四边坐标，数值等价）。
- 全套验证：Linux 刮擦副本 `cargo test` 全过（基线 281 + 新增
  3 = 284，断言无削弱）；Windows 目标 `cargo check --all-targets`
  与 `clippy --all-targets -D warnings` 干净；`cargo fmt --check`
  通过。宿主绘制参数的实际生效（回退时上屏为胡桃木默认框）属
  真机复核范围，与专题各工单的 needs-info 清单同批核。

## Consequences

- 回退口径自此只有一处定义：改默认画框只动默认常量与裁决，
  宿主与配置层不会再各自漂移。
- 布局接缝成为画框绘制矩形的唯一产地：内置三层、阴影、九宫
  格同口径，后续给自定义相框图加绘制特性时只在一处扩展。
- 生效外观携带参数后，内置绘制函数成为「给什么参数画什么」
  的纯消费方；设置窗调整用户参数不影响正在回退中的画框（回
  退画默认框，直到相框图恢复或用户切回内置模式）。

# 侧边单击等双击窗口结束

Status: accepted

点击图片左右 20% 会切换，双击会用系统看图器打开第一下按下时正在显示的那张。若侧边第一下立即切换，双击打开的就是下一张，不是用户瞄准的那张。因此单击要等系统双击时间结束才成立，除非下一次按下已经超出系统双击距离，或移动已经超过系统拖动阈值。双击本身不切换。

## Considered Options

- 侧边第一下立即切换，双击打开切换后的那张。侧边切换没有延迟，但双击会打开用户没有瞄准的图。
- 写死等待时间和距离，不读系统设置。测试更稳，但和已经选定的系统拖动阈值不一致，用户改了系统双击速度这里也不会跟着变。

## Consequences

- 侧边单击会晚一个 `GetDoubleClickTime`。
- 实现和测试不能把侧边按下并松开当成立即切换。
- 延迟后才成立的切换，仍并入动画中的最后一次意图。
- 悬停条不在本决定内。


后续图片区单击不再切图，见 [相框按当前图像比例自适应宽度](../../.agents/notes/implemented/feature/2026-11-22-image-driven-frame.md)。本 ADR 记录侧边单击导航的历史权衡，不再作为当前图片区导航规范。

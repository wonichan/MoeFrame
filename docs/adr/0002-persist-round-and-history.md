# 本轮进度与历史分开保存

Status: accepted

随机模式既要重启后续播，又要避免新选择重复本轮已看过的图。`current_image` 只知道退出前的一张，洗牌袋不跨启动保存。因此恢复当前图是防重复的例外；本轮进度记录已看路径，历史记录显示顺序。二者都跨启动保存，但不能互相改写。

新一轮只在当前图库全部看完后开启。图库至少两张时，新一轮第一张避开上一轮最后成功显示的图。这个避让不作用于重启时恢复当前图。

## Considered Options

- 每次重启都把除当前图外的路径洗成新一轮。启动规则简单，但跨启动仍会重新抽到刚看过的图，防重复没有延续。
- 保存完整洗牌袋。重启后的剩余顺序可复现，但配置会承担一份不需要承诺的随机顺序，也没有解决回看与防重复是两件不同事情的问题。
- 只用一份历史兼任本轮进度。存储更少，但回看会改变哪些图仍算未看，向前播放和回看互相污染。

## Consequences

- 配置必须新增本轮进度和历史，不能只凭 `current_image` 实现随机续播。
- 重启后允许再次看到退出前的当前图，但新的自动或手动选择不得重复本轮已看路径。
- 历史上限是 512 条。回看不修改本轮进度，必须先回到最新图，才继续未看路径。
- 顺序模式不使用这套随机规则。

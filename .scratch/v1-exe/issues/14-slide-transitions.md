# 14: 方向正确、连点不乱的滑动切换

**What to build:** 用户前后切换图片时看到方向清楚、约 300ms 的自然滑动；连续操作不会并行动画或乱序，目标图片加载较慢时仍保留当前画面。

**Blocked by:** [11: 顺序浏览与定时轮播](11-sequential-slideshow.md)。

**Status:** resolved

## Acceptance criteria

- [x] 始终使用约 300ms、ease-out 的滑动动画；下一张从右向左进入，上一张从左向右进入，不提供淡入淡出、无动画等 P1 选择。（宿主 SLIDE_SECONDS=0.3 三次 ease-out；animation 配置键维持只存不用）
- [x] 手动导航与自动轮播共用转场行为，动画方向反映用户的前后导航，不因目标图片排序或加载完成顺序而反转。（方向在产生候选时由导航意图定死，随在飞加载带到 StartTransition）
- [x] 动画期间只保留最后一个新切换意图，先前未执行意图被替换；当前动画结束后再处理，不启动并行动画，也不按点击次数累积播放。（与加载期间共用同一条只留最后意图的队列，行为测试覆盖连续相反意图）
- [x] 目标未就绪时保持当前图，不闪白；读取、解码和缩放仍在后台，拖动及 UI 不被等待阻塞。（既有后台加载不变；转场开始前视图与纹理都停在源图）
- [x] 失败或已失效的目标按既定规则跳过，预加载或失败结果不更新当前图、本轮进度或历史。成功显示才提交切换结果。（提交点后移到转场完成：记账与落盘只发生在 TransitionCompleted）
- [x] 自动间隔、暂停和手动重计语义继续成立；动画不是另一份轮播计时器，不制造额外成功显示事件。（Tick 在转场期间挂起，截止点在提交时从完成时刻重设；转场中暂停仍提交显示但不计时，有测试）
- [x] 转场允许当前图和目标图暂时同时存在；动画完成后立即释放切走图的纹理及不再需要的数据，长期仍只留当前图与下一张显示数据。（宿主 incoming/outgoing 双纹理同绘，完成时旧 handle 随替换释放）
- [x] 通过应用行为入口控制时间及加载结果，测试上下张方向、动画中连续相反意图、只执行最后意图、慢图、失败、暂停及资源生命周期结果；不绑定 GUI 帧数或线程调度。（行为测试 6 项新增；慢图/失败对转场路径的覆盖另有工单 11/12 既有测试与本票「转场后失败保留新图」一项）
- [ ] 在真实相框中演示自动切换与快速连续导航，确认无白屏、无并行动画和明显方向错误，记录检查结果。（未做：并入仓库根目录 real-machine-check-10-14.md 的工单 14 一节，与工单 10–13 合并实机确认，本票因此 needs-info）

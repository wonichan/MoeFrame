# 14: 方向正确、连点不乱的滑动切换

**What to build:** 用户前后切换图片时看到方向清楚、约 300ms 的自然滑动；连续操作不会并行动画或乱序，目标图片加载较慢时仍保留当前画面。

**Blocked by:** [11: 顺序浏览与定时轮播](11-sequential-slideshow.md)。

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 始终使用约 300ms、ease-out 的滑动动画；下一张从右向左进入，上一张从左向右进入，不提供淡入淡出、无动画等 P1 选择。
- [ ] 手动导航与自动轮播共用转场行为，动画方向反映用户的前后导航，不因目标图片排序或加载完成顺序而反转。
- [ ] 动画期间只保留最后一个新切换意图，先前未执行意图被替换；当前动画结束后再处理，不启动并行动画，也不按点击次数累积播放。
- [ ] 目标未就绪时保持当前图，不闪白；读取、解码和缩放仍在后台，拖动及 UI 不被等待阻塞。
- [ ] 失败或已失效的目标按既定规则跳过，预加载或失败结果不更新当前图、本轮进度或历史。成功显示才提交切换结果。
- [ ] 自动间隔、暂停和手动重计语义继续成立；动画不是另一份轮播计时器，不制造额外成功显示事件。
- [ ] 转场允许当前图和目标图暂时同时存在；动画完成后立即释放切走图的纹理及不再需要的数据，长期仍只留当前图与下一张显示数据。
- [ ] 通过应用行为入口控制时间及加载结果，测试上下张方向、动画中连续相反意图、只执行最后意图、慢图、失败、暂停及资源生命周期结果；不绑定 GUI 帧数或线程调度。
- [ ] 在真实相框中演示自动切换与快速连续导航，确认无白屏、无并行动画和明显方向错误，记录检查结果。

## Context

父规格：[V1 可运行程序规格](../spec.md)，重点为轮播、动画、后台加载与成功显示后提交状态。

# 12: 随机防重复与实际历史回看

**What to build:** 用户默认以随机模式看遍图库，再进入下一轮；上一张能回到实际看过的图片，向前先回到最新图，再继续未看图片，回看不会打乱本轮进度。

**Blocked by:** [11: 顺序浏览与定时轮播](11-sequential-slideshow.md)。

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 菜单提供顺序与随机二选一，勾选反映实际模式，选择保存；无已保存选择时默认随机。自动轮播和手动导航共用同一套播放行为。
- [ ] 随机模式以洗牌袋生成播放序列，新选择只来自本轮未看路径；当前图库全部看完后才开启新一轮。
- [ ] 图库至少两张时，新一轮第一张不同于上一轮最后成功显示的图；只有一张时保持显示，不套用防重复或轮间避让。空图库不崩溃、不忙循环。
- [ ] 本轮进度只记录本轮成功显示过的路径；历史按实际成功显示顺序保存最近 512 条，二者不能互相代用，不保存图片像素。
- [ ] 随机模式上一张按历史回看，不消耗或回退本轮进度；已经不在图库的路径自动跳过。
- [ ] 回看后，下一张或轮播先沿历史回到最新图，再继续本轮未看路径；回看不伪造新的随机选择或破坏轮间规则。
- [ ] 候选图、预加载、读取或解码失败、缺失和超限路径不进入本轮进度或历史；仅成功显示允许提交当前图片路径及相关状态。
- [ ] 播放模式切换不额外重置计时；原有顺序、暂停、手动重计和加载失败行为保持正确。
- [ ] playlist 按先测试后实现覆盖轮内无重复、轮间避让、一张与零张、历史回看与返回最新、512 条上限及失败不记账；断言不变量，不固定整段随机排列。
- [ ] 应用行为测试用可控加载结果和随机性验证用户切换、自动轮播及回看的最终显示和记账结果，不绑定内部容器、私有函数或随机调用次数。

# 11: 顺序浏览与定时轮播

**What to build:** 用户能按完整路径自然序循环浏览图库，用键盘、滚轮或菜单切换图片、暂停和恢复轮播，并选择会被保存的间隔；每次手动切换后都能完整欣赏新图一个间隔。

**Blocked by:** [10: 首次启动，选文件夹看到第一张图](10-first-image.md)。

**Status:** needs-info

## Acceptance criteria

- [x] 顺序模式按完整路径自然排序，连续数字按数值比较，其余按 Unicode 码点比较，不按拼音；到末尾后循环回开头。
- [x] 上一张和下一张可以通过相框右键菜单、聚焦时的左右方向键及滚轮触发；滚轮向上为上一张，向下为下一张。单图和空图库不越界、不忙循环。
- [x] 默认间隔为 30 秒。菜单提供 10 秒、30 秒、1 分钟、5 分钟、10 分钟、30 分钟六档，当前选项与实际生效值一致并保存。
- [x] 自动轮播按有效间隔触发；手动成功切换后重新计满间隔。加载期间保留当前图，不把失败候选当作成功切换。
- [x] 菜单和聚焦相框时的空格均可播放或暂停；暂停只停止自动切换，仍能手动导航，恢复播放后按有效间隔计时。
- [x] 间隔有效值变化时从生效时刻重新计满；相同值不重计、不重写。暂停中改间隔只记录新值，恢复时计满。显示模式或播放模式变化本身不额外重置计时。
- [x] 成功显示当前图后预加载下一张；长期只留当前图与下一张显示数据，非预加载方向允许等待但不闪白，资源限制不因轮播失效。
- [x] playlist 的自然序、循环、空图库和单图行为先写测试再实现；时间通过可控推进验证，不用真实 sleep 等待轮播。
- [x] 应用行为测试覆盖菜单、键盘和滚轮的共同导航结果（自动化部分已完成并全绿；方向键/滚轮/菜单的真实窗口触发待 Windows 实机记录，见下方 Comment）、自动切换、暂停中手动切换、手动重计、变更与同值间隔、失败加载不提交。已有真实文件测试继续通过。

# 15: 点击、双击、拖动分界与当前图操作

**What to build:** 用户既能拖动相框，又能用侧边点击切换、双击打开瞄准的原图和右键操作当前图，互相之间不误触，动画期间也保持明确的操作结果。

**Blocked by:** [14: 方向正确、连点不乱的滑动切换](14-slide-transitions.md)。

**Status:** resolved

## Acceptance criteria

- [x] 采用 Windows 系统拖动阈值及系统双击时间、距离，不写死另一套值。移动超过拖动阈值后成为拖动，松开不切换；边缘缩放不误触内容移动或点击。（宿主启动时读 SM_CXDRAG/SM_CYDRAG/GetDoubleClickTime/SM_CXDOUBLECLK/SM_CYDOUBLECLK 并按缩放换算注入核心；边缘按下只缩放不进手势判定）
- [x] 左、右各 20% 区域点击分别为上一张、下一张，中间 60% 单击无动作；侧边单击等待系统双击窗口结束才成立。（双击窗口锚在第一下按下时刻，与系统口径一致）
- [x] 双击要求两次按下均未成为拖动，且在系统双击时间和距离内；双击本身不切换，用系统默认看图器打开第一下按下时相框正在显示的原图，而非即将进入的目标图。（目标路径在第一下按下时即冻结）
- [x] 等待第二下时，新按下超出双击距离或移动超过拖动阈值，先把第一下按单击结算，新按下重新判断，不与第一下组成双击。（移动通道与松开位移通道都能触发即时结算）
- [x] 右键只打开菜单并取消未完成左键动作，含等待双击的单击；若正在拖动，先恢复到该次按下时的位置，再打开菜单。已在播放的动画不取消。（核心产出 RollbackFrameDrag 效果，宿主恢复按下时记录的窗口位置；系统拖动环内的右键取消由系统本身处理，待实机确认）
- [x] 动画中拖动只移动相框，不切换、不打断动画；双击不产生切换；已经成立的导航意图仍遵循只保留最后一次的规则。（手势结果统一走核心 navigate 的排队规则，行为测试覆盖转场中结算）
- [x] 相框菜单补齐打开当前原图、打开其所在文件夹和复制图片路径；目标是当前成功显示的原图路径，中文、空格和特殊字符路径均正确。（路径以 PathBuf 原样交给系统打开命令，不做字符串拼接；剪贴板用 to_string_lossy）
- [x] 通过应用行为入口测试单击等待、双击目标固定、超距重新判定、拖动不切换、右键取消及位置回滚、动画中手势和最后意图，使用可控时间而非真实 sleep。（行为测试 9 项，阈值与时间全由测试注入）
- [ ] 用户或明确的实机执行人实际验证拖动、系统双击、右键与动画冲突，以及默认看图器、文件夹和剪贴板操作；mock、截图或 API 成功不能替代实际结果，未验证项不标通过。（未做：并入仓库根目录 real-machine-check-10-15.md 的工单 15 一节，与工单 10–14 合并实机确认，本票因此 needs-info）

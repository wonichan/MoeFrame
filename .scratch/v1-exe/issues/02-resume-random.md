# 重启后续播

Label: wayfinder:grilling
Type: grilling
Status: claimed

## Question

重启后要从 `current_image` 继续，而不是每次从第一张开始。配置里没有洗牌袋，也没有历史。

随机模式，且图库至少两张时，要决定：

- 是否先显示 `current_image`，再将其余路径洗成新的播放序列。
- 新序列的第一张是否不得与刚显示的这张相同。这是不是把「一轮衔接」用到了重启。
- 历史是否只从这次启动重新开始。刚启动时，「上一张」是否不可用。
- `current_image` 已不在图库时，是否跳到新播放序列的下一张，并重写配置。

顺序模式若已由文档钉死，明确写「顺序模式无新决定」，并写清你采用的那一条：按自然序定位到该路径，缺失则跳到排序中的下一张。不要另发明规则。

# 13: 重启恢复当前图、本轮进度与历史

**What to build:** 用户退出并重新启动相框后，先看到上次当前图，再继续未看图片；上一张仍能回看最近历史，配置的局部损坏不会把其他有效偏好一并清空。

**Blocked by:** [12: 随机防重复与实际历史回看](12-random-history.md)。

**Status:** needs-info

## Acceptance criteria

- [x] 当前图片路径、本轮进度、历史分别持久化，后两者只保存路径，历史最近 512 条；不保存洗牌袋，不承诺重启后的剩余随机顺序完全相同。（配置 [general] 的 current_image/round_seen/history 三字段，每次成功显示一并落盘）
- [x] 当前图仍在图库时，启动先恢复它。再次显示退出前当前图是防重复例外，不应用轮间首尾避让；恢复后新的选择仍受已保存本轮进度约束。（恢复落位走 land_restored 只落位不记账）
- [x] 回看位置和历史恢复遵循父规格的规则；上一张仍跳过不在图库的路径，回看不改本轮进度，向前和轮播先回到最新图再继续未看图片。（游标恢复到当前图在历史中的最后位置；当前图不在历史中时上一张可回看整段历史）
- [x] 随机模式当前图已不在图库时，清空旧本轮进度，对当前图库开始新一轮，找到首个可加载图片后才更新当前图及成功显示状态；缺失旧路径不追加为新历史。
- [x] 顺序模式恢复当前图位置；当前路径缺失时，取自然序中该路径之后的下一张，必要时循环寻找可加载图片。（自然序后继位置由图库模块计算，核心不复制排序规则）
- [x] 预加载及失败候选不提前写成已显示；启动遇到坏图、超限图片或无可用图片时仍可继续操作，不无限重试同一失败集合。（SaveResumeState 只在成功落位后发出；恢复图加载失败时候选链继续按模式找下一张）
- [x] 当前图片路径、本轮进度、历史字段分别校验，损坏字段丢弃并按缺失处理，不因一个字段损坏清空其他合法状态。（当前图字段缺失即按缺失处理，不拿历史尾部冒充——Spec 审查后修正）
- [x] 配置可恢复时只修坏字段，保留合法手改值；配置不可读时恢复合法默认配置而不崩溃。间隔越界整数钳制到 3 或 99999999，小数、损坏或缺失回退 30，修复结果写回。（间隔与整体修复为工单 10/11 既有行为，本票回归测试继续通过）
- [x] 保留三项 P1 配置键的合法值，非法值按既定默认值修复，不让这些键驱动运行行为；不监视配置文件，手改按重启生效。（既有行为，本票未触碰）
- [x] playlist 的恢复与缺失路径规则先写测试再实现；应用行为和真实配置文件测试跨两次应用启动验证恢复、防重复、历史上限、成功后落盘及局部损坏修复。（行为测试含跨两次启动续播；配置测试用真实文件跨两次加载往返）

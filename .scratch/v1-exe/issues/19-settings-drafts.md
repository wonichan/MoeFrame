# 19: 路径与秒数编辑：草稿、提交和校验

**What to build:** 用户在设置窗编辑文件夹路径或自定义秒数时，不会因打字触发扫描或计时变化；提交、关闭、重新扫描及菜单改值各有明确结果，输入失误不会抹掉有效间隔。

**Blocked by:** [16: 手动重扫后继续当前轮](16-manual-rescan.md)、[18: 设置窗：即时设置与独立生命周期](18-settings-window.md)。

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 设置窗补齐路径框、重新扫描按钮及自定义秒数框，不增加独立文件夹选择器；菜单选择文件夹仍是原有入口。
- [ ] 路径和秒数输入期间只形成草稿，不扫描、不改变计时，也不将中间文字写成已生效配置。
- [ ] 失焦或回车时去掉首尾空白后提交；点击相框或设置窗其他普通控件算失焦，回车提交后焦点仍在输入框。
- [ ] 点击重新扫描只扫描已生效路径，不提交路径或秒数草稿，不能由该按钮触发的失焦绕过此例外。
- [ ] 关闭按钮、设置窗 Alt+F4 或 Esc 丢弃未提交文字，不借关闭导致的失焦提交；重新打开显示实际生效值。
- [ ] 菜单或预设修改同一项时，丢弃该项未提交草稿并显示生效值；菜单选择文件夹同样覆盖路径草稿。其他项不被无故改写。
- [ ] 秒数仅接受普通十进制整数，范围 3 到 99999999。空白、小数或解析失败保留上次有效值，不回退 30；可解析但越界的整数钳制到边界，并显示提交结果。
- [ ] 间隔有效值变化才保存并重新计满；同值不重计、不重写。暂停中提交只记录新值，恢复时计满；模式或显示方式切换不附带重计。
- [ ] 无效、空白、指向文件或不存在的文件夹路径保留提交文本，图库进入空状态，不反复弹窗；有效路径提交后真正更新图库，沿用既定增删和续播规则。
- [ ] 输入框解析失败与配置读取修复保持两套规则，不将输入框错误改成默认 30，也不让配置中的坏值原样继续生效。
- [ ] 通过应用行为入口和真实临时目录、配置文件测试打字不生效、回车、普通失焦、重扫例外、全部关闭路径、菜单覆盖、无效路径及秒数边界；用可控时间断言计时，而非控件私有状态。
- [ ] 实际操作验证回车保留焦点、关闭不误提交及重新扫描不提交草稿，记录结果。

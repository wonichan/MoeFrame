# 16: 手动重扫后继续当前轮

**What to build:** 用户向收藏文件夹增删图片后，从菜单主动重新扫描，就能看到新增图片并避开删除路径；仍有效的当前图不被打断，重启后也不会因扫描丢失正确的本轮进度和历史。

**Blocked by:** [13: 重启恢复当前图、本轮进度与历史](13-resume-state.md)。

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 相框菜单提供手动重新扫描，针对当前已生效的根文件夹递归枚举路径，不预解码全部图片；菜单更换文件夹后也更新实际图库。
- [ ] 当前图仍有效时，重扫不打断它；删除路径从本轮进度及后续播放剔除，新增路径作为本轮未看图片。
- [ ] 仍有未看旧路径时继续当前轮，不因增删整轮重洗；自然序模式按新图库的完整路径自然序继续导航。
- [ ] 历史回看跳过已经不在图库的路径，不把删除路径或失败加载写成新历史，也不因重扫将回看混成本轮进度。
- [ ] 当前路径缺失时沿用父规格已定规则：随机清空旧本轮进度并开始新一轮；顺序从缺失路径之后定位；找到可显示图片后才提交更新。
- [ ] 扫描后的有效当前图、本轮进度与历史正确保存，下一次启动与本次继续播放一致，不恢复已剔除的路径状态。
- [ ] 目录为空、无效或变成文件时保持可操作的空状态；坏图和超限图片继续安全跳过并记日志，不产生无限扫描或加载循环。
- [ ] playlist 的图库增删行为先写测试再实现，覆盖删除、增加、剩余未看旧图、当前有效与缺失、历史缺失路径及空图库；不以定时重扫或文件监听替代输入。
- [ ] 应用行为和真实临时目录测试完整执行增删文件、手动重扫、导航、配置落盘及重启，断言可见图片与状态不变量，而非扫描器内部调用次数。

## Context

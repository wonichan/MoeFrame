# 17: 托盘常驻：关闭不退出

**What to build:** 用户关闭相框后，程序和轮播仍在托盘中运行；可以从托盘找回相框或控制浏览，只有明确选择退出才结束进程。

**Blocked by:** [11: 顺序浏览与定时轮播](11-sequential-slideshow.md)。

**Status:** resolved

## Acceptance criteria

- [x] 程序运行时托盘图标常驻；左键单击切换相框显示与隐藏，反复操作不创建重复相框或托盘图标。（托盘首帧懒建一次、退出时才摘除；切换只认左键抬起沿，经核心 ToggleVisibilityRequested 交替产出 Show/HideFrame，行为测试覆盖交替切换；图标实际出现待实机）
- [x] 托盘右键菜单提供显示或隐藏、播放或暂停、上一张、下一张、设置和退出；随功能票逐步接入的设置入口不得伪报已生效。（菜单含关闭/显示相框、暂停/播放、上一张、下一张、退出，文案从核心现读同步；「设置」按本票 Context 未接入前不展示，待工单 18 接入设置窗时补入）
- [x] 关闭相框，包括 Alt+F4，只隐藏它，不结束进程、不取消播放状态；正在播放时，隐藏期间仍按有效间隔轮播，再显示时看到实际当前图。（宿主同帧 CancelClose 拦截并转核心 CloseRequested，只动可见性；隐藏轮播与唤回当前图有行为测试；隐藏期间宿主以 250ms 心跳保活事件轮询，实机时延待验）
- [x] 托盘导航与播放或暂停使用相同应用行为，隐藏状态下也有效，不维护另一份播放状态或历史。（托盘菜单与左键全部映射既有核心意图，行为测试覆盖隐藏中自动轮播、手动导航与暂停）
- [x] 托盘和相框菜单显示真实的播放及显示状态；相框菜单或托盘明确选择退出才结束进程，并正确完成已有状态保存和资源清理。（托盘文案随 core.frame_visible()/is_playing() 变化同步，相框菜单播放文案原已按状态；退出只有 ExitRequested 一路，落盘是显示提交时增量完成的，无退出前未保存状态；退出时先摘托盘图标）
- [x] 显示或隐藏相框不被等同于打开或关闭设置窗；后续设置窗接入时沿用独立生命周期，不为此预建无效 P1 功能。（可见性状态只管相框窗口；未预建任何设置窗结构）
- [x] 应用行为测试覆盖关闭与退出分离、隐藏时轮播与手动导航、暂停、反复唤回和持久化结果，不用 mock 返回成功证明托盘实际存在。（行为测试 4 项断言核心状态与效果含 SaveResumeState 内容；托盘存在性只认实机标准 8）
- [ ] 明确实机执行人，在 Windows 实际操作托盘左键、右键、相框 Alt+F4、隐藏后唤回及明确退出，记录进程是否存在和显示图是否延续；未验证项不标通过。（未做：并入仓库根目录 real-machine-check-10-17.md 的工单 17 一节，含「暂停→隐藏→托盘唤回」与「隐藏状态下从托盘退出」两项必查，本票因此 needs-info）

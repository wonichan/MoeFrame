# 18: 设置窗：即时设置与独立生命周期

**What to build:** 用户从相框菜单或托盘打开同一块独立设置窗，立即调整播放模式、间隔预设及适应或填充；所有入口反映同一份已保存状态，设置窗不会改变相框的隐藏和轮播状态。

**Blocked by:** [12: 随机防重复与实际历史回看](12-random-history.md)、[17: 托盘常驻：关闭不退出](17-tray-lifecycle.md)。

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 相框菜单和托盘的设置命令打开同一块非模态设置窗，已打开时带到前台，不创建多个互相冲突的副本；没有确定或取消按钮。
- [ ] 设置窗显示顺序或随机、六档间隔预设、适应或填充；选择立即生效并保存，与相框菜单及实际行为同步，不产生第二份配置状态。
- [ ] 适应完整显示图片且不变形、默认纯黑留白；填充按比例铺满并居中裁剪，按物理窗口的覆盖尺寸生成显示数据。保持内边距上限，不支持 Stretch。
- [ ] 模式和显示方式改变不额外重置计时；间隔改变、同值选择及暂停中修改仍符合既定计时规则。
- [ ] 设置窗默认位于相框所在屏幕中央；相框隐藏或不在任何屏幕上时位于主屏中央。设置窗位置不保存、不随相框移动。
- [ ] 关闭按钮、设置窗 Alt+F4 和 Esc 只关闭设置窗，不暂停轮播、不退出进程、不隐藏相框；相框可在设置窗打开时独立隐藏。
- [ ] 相框隐藏时，从托盘打开设置窗不唤出相框。关闭或重新打开设置窗不改变已生效设置。
- [ ] 不展示悬停暂停、动画类型或显示文件名控件；三项 P1 保留键合法值仍被保存，但不控制行为。始终滑动、悬停不暂停、不显示文件名。
- [ ] 通过应用行为入口和真实配置读写验证即时生效、菜单同步、相同值不重复计时、关闭与隐藏独立、仅一块设置窗及横竖图显示结果；补充实际 Windows 窗口生命周期操作记录。

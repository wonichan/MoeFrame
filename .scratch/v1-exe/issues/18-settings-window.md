# 18: 设置窗：即时设置与独立生命周期

**What to build:** 用户从相框菜单或托盘打开同一块独立设置窗，立即调整播放模式、间隔预设及适应或填充；所有入口反映同一份已保存状态，设置窗不会改变相框的隐藏和轮播状态。

**Blocked by:** [12: 随机防重复与实际历史回看](12-random-history.md)、[17: 托盘常驻：关闭不退出](17-tray-lifecycle.md)。

**Status:** needs-info

## Acceptance criteria

- [x] 相框菜单和托盘的设置命令打开同一块非模态设置窗，已打开时带到前台，不创建多个互相冲突的副本；没有确定或取消按钮。（宿主即时视口，固定 ViewportId + settings_open 单状态；已开只发 Focus；实际聚焦手感待实机）
- [x] 设置窗显示顺序或随机、六档间隔预设、适应或填充；选择立即生效并保存，与相框菜单及实际行为同步，不产生第二份配置状态。（模式/间隔派发既有核心意图，菜单与设置窗都现读核心；显示方式经新增的相框菜单「显示方式」子菜单双向同步，共用 apply_fit_mode，落盘走 ConfigStore::set_fit_mode 真实文件往返测试）
- [x] 适应完整显示图片且不变形、默认纯黑留白；填充按比例铺满并居中裁剪，按物理窗口的覆盖尺寸生成显示数据。保持内边距上限，不支持 Stretch。（绘制几何抽库 display::display_size，横竖图×两模式共六项测试；解码缝工单 09 已按 Fill 覆盖尺寸生成数据，运行时切换经哨兵序号重载当前图换纹理，观感待实机）
- [x] 模式和显示方式改变不额外重置计时；间隔改变、同值选择及暂停中修改仍符合既定计时规则。（与菜单同一意图入口，工单 11/12 既有核心测试守此规则；显示方式只走宿主重载，不经核心、不动截止时刻）
- [x] 设置窗默认位于相框所在屏幕中央；相框隐藏或不在任何屏幕上时位于主屏中央。设置窗位置不保存、不随相框移动。（打开那一帧按相框视口 monitor_size 计算一次，之后不再施加；近似如实记录：egui 给不出屏幕原点与主屏信息，单屏精确，多屏按相框所在屏左上角近似，隐藏且拿不到尺寸时回落系统默认位置；实机在单屏环境验收）
- [x] 关闭按钮、设置窗 Alt+F4 和 Esc 只关闭设置窗，不暂停轮播、不退出进程、不隐藏相框；相框可在设置窗打开时独立隐藏。（关闭只置宿主标记、不派发任何核心意图，相框关闭拦截只读相框视口；实际按键手感待实机）
- [x] 相框隐藏时，从托盘打开设置窗不唤出相框。关闭或重新打开设置窗不改变已生效设置。（托盘设置路径不发任何显示相框命令，重开时全部现读核心与宿主状态；待实机）
- [x] 不展示悬停暂停、动画类型或显示文件名控件；三项 P1 保留键合法值仍被保存，但不控制行为。始终滑动、悬停不暂停、不显示文件名。（ADR-0003；set_fit_mode 的字段级更新保留合法手改值，Spec 审查核对无任何代码把三键读成行为）
- [ ] 通过应用行为入口和真实配置读写验证即时生效、菜单同步、相同值不重复计时、关闭与隐藏独立、仅一块设置窗及横竖图显示结果；补充实际 Windows 窗口生命周期操作记录。（自动化部分已齐：几何六项 + 配置往返 + 既有核心计时测试；窗口生命周期实录未做，并入仓库根目录 real-machine-check-10-18.md 的工单 18 一节，本票因此 needs-info）

# 21: 开机自启与失败回滚

**What to build:** 用户从相框菜单或设置窗控制开机自启，界面、已保存配置与系统实际状态一致；设置失败时保留原状态且不弹窗打扰。

**Blocked by:** [18: 设置窗：即时设置与独立生命周期](18-settings-window.md)。

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 相框菜单和设置窗提供有效的开机自启开关，两处反映同一真实状态，改动立即执行并在成功后保存。
- [ ] 使用父规格指定的当前用户 Run 项和应用项名，不写系统级自启项；除该项外，业务配置仍只使用已有配置契约，不转移到注册表。
- [ ] 启动读取及用户切换时，开关不只反映一个过时配置布尔值，须与实际系统自启状态一致。
- [ ] 写入或移除失败时，开关与配置回到操作前状态，不伪报成功、不弹窗；合法的其他设置不受影响。
- [ ] 启动目标正确指向实际程序，程序路径含中文、空格或特殊字符时仍正确；不因此引入安装器、后台服务或联网行为。
- [ ] 自启操作不改变相框显示或隐藏、设置窗生命周期、当前图、轮播暂停状态及间隔计时。
- [ ] 应用行为测试通过可控系统操作结果验证成功同步、失败回滚、同一状态的菜单与设置窗展示及配置保存；mock 仅证明应用行为，不代替真实系统验证。
- [ ] 明确实机执行人，在 Windows 验证启用、禁用、实际自启目标及可复现的失败路径，记录系统状态与界面结果；测试后恢复测试前的自启状态，不覆盖用户已有无关项。

## Context

父规格：[V1 可运行程序规格](../spec.md)，重点为菜单、开机自启与配置契约；设置窗范围沿用 [ADR-0003](../../../docs/adr/0003-settings-window-boundary.md)。

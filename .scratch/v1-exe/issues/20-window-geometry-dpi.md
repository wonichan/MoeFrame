# 20: 窗口位置恢复、宽高比锁定与多屏显示

**What to build:** 用户摆好和缩放相框后，重启仍能恢复；可以从设置窗锁住当前宽高比或恢复默认位置与大小，跨屏、换 DPI、拔掉副屏后相框依然可见且图片显示正确。

**Blocked by:** [18: 设置窗：即时设置与独立生命周期](18-settings-window.md)。

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 相框位置、尺寸和宽高比锁定开关保存并跨启动恢复；合法手改值保留，局部无效值按配置契约修复，不清空其他合法偏好。
- [ ] 宽高比锁定默认关闭；从设置窗打开时锁住那一刻的窗口比例，不固定成 480×320 的默认比例，不加入相框右键菜单。
- [ ] 锁定后拖四边或四角仍保持选定比例，同时任一边不得小于 120 逻辑尺寸；关闭锁定后可自由缩放。边缘缩放不误触拖动或切换。
- [ ] 锁定不改变适应或填充，不重置轮播间隔，不与图片自身比例混同。
- [ ] 设置窗提供恢复默认位置与大小，立即变为 480×320、当前屏幕右下角内缩 24px，并保存；锁定开启时锁定比例同步更新为默认尺寸比例。
- [ ] 相框隐藏时恢复默认使用主屏，并显示相框；这与仅从托盘打开设置窗不唤出相框的规则保持区别。
- [ ] 启动恢复位置落到已移除屏幕范围之外时，钳制回主屏可见区域，不丢失相框。设置窗位置仍不保存、不随相框移动。
- [ ] 在显示器 DPI 或窗口物理尺寸变化后，按实际物理像素需求更新图片显示数据；填充按覆盖尺寸计算，旧数据及时释放，不保留全分辨率或跨尺寸大缓存。
- [ ] 应用行为及真实配置读写测试覆盖比例捕获、最小尺寸、默认恢复、隐藏时显示、重启恢复、非法字段和离屏位置；不绑定私有几何函数。
- [ ] 明确实机执行人，验证四边四角、锁定开关、相框恢复、实际可用的多屏和 DPI 路径。记录系统、屏幕、DPI 与物理尺寸，未具备的环境保持未验证，不冒充兼容性通过。

# 20: 窗口位置恢复、宽高比锁定与多屏显示

**What to build:** 用户摆好和缩放相框后，重启仍能恢复；可以从设置窗锁住当前宽高比或恢复默认位置与大小，跨屏、换 DPI、拔掉副屏后相框依然可见且图片显示正确。

**Blocked by:** [18: 设置窗：即时设置与独立生命周期](18-settings-window.md)。

**Status:** needs-info

## Acceptance criteria

- [x] 相框位置、尺寸和宽高比锁定开关保存并跨启动恢复；合法手改值保留，局部无效值按配置契约修复，不清空其他合法偏好。（几何停稳 0.6s 防抖落盘 + 退出时冲刷未落盘的最后几何；window 坏字段修复有真实文件测试。已知行为：整窗摆在副屏会被启动钳制移回主屏，见标准 7 注）
- [x] 宽高比锁定默认关闭；从设置窗打开时锁住那一刻的窗口比例，不固定成 480×320 的默认比例，不加入相框右键菜单。（默认关由配置修复保证；打开瞬间以每帧更新的实际内尺寸捕获；菜单未加项）
- [x] 锁定后拖四边或四角仍保持选定比例，同时任一边不得小于 120 逻辑尺寸；关闭锁定后可自由缩放。边缘缩放不误触拖动或切换。（口径如实记：修正是「停稳后一次性纠正」而非拖动中保持——指针未按下且尺寸变化时按 aspect_locked_size 下发修正，纯函数覆盖宽/高/角驱动与最小边触底反推；拖动中手感待实机标准 10）
- [x] 锁定不改变适应或填充，不重置轮播间隔，不与图片自身比例混同。（锁定路径只读写锁定状态与窗口尺寸，比例来源是窗口内尺寸）
- [x] 设置窗提供恢复默认位置与大小，立即变为 480×320、当前屏幕右下角内缩 24px，并保存；锁定开启时锁定比例同步更新为默认尺寸比例。（立即下发并落盘；「当前屏」口径 = 相框所在屏的 monitor_size，只有尺寸无原点，多屏落位精度待实机；monitor 缺失时不下发位置命令、落盘沿用旧坐标，尺寸仍为默认）
- [x] 相框隐藏时恢复默认使用主屏，并显示相框；这与仅从托盘打开设置窗不唤出相框的规则保持区别。（隐藏时经核心 ToggleVisibilityRequested 显示，request_settings 未改、区别成立；「主屏」口径同标准 5 的 monitor 局限，位置缺失时在原地显示——待实机）
- [x] 启动恢复位置落到已移除屏幕范围之外时，钳制回主屏可见区域，不丢失相框。设置窗位置仍不保存、不随相框移动。（首帧只查一次，完全无交集才钳。**明确行为警告**：egui 无屏幕枚举/原点，整窗合法摆在副屏也会被判离屏、启动时移回主屏右下角——当前不保存副屏摆放，防拔屏丢窗优先；设置窗定位代码未动）
- [x] 在显示器 DPI 或窗口物理尺寸变化后，按实际物理像素需求更新图片显示数据；填充按覆盖尺寸计算，旧数据及时释放，不保留全分辨率或跨尺寸大缓存。（physical_target 汇合尺寸与 DPI，停稳 250ms 后经哨兵重载换纹理，texture_target/load_target 记账，在飞核心加载已按新目标发出则跳过；旧纹理随替换释放）
- [x] 应用行为及真实配置读写测试覆盖比例捕获、最小尺寸、默认恢复、隐藏时显示、重启恢复、非法字段和离屏位置；不绑定私有几何函数。（已覆盖：锁定推导/最小边、离屏钳制、几何+锁定真实文件往返、window 坏字段修复；被测纯函数是库公开面（同工单 18 display_size 先例）。未覆盖如实记：比例捕获、恢复默认、隐藏时显示均在 Windows-only 宿主，无自动化，归实机标准 10）
- [ ] 明确实机执行人，验证四边四角、锁定开关、相框恢复、实际可用的多屏和 DPI 路径。记录系统、屏幕、DPI 与物理尺寸，未具备的环境保持未验证，不冒充兼容性通过。（未做：并入仓库根目录 real-machine-check-10-20.md 的工单 20 一节，含副屏/DPI 的「未验证」口径，本票因此 needs-info）

# 10: 首次启动，选文件夹看到第一张图

**What to build:** 用户启动真实相框、选一个文件夹，就能在可移动和缩放的无边框窗口看到收藏；取消选择、空图库或坏图时仍有可操作的界面，下次启动无需重复选择已保存的文件夹。

**Blocked by:** [08: 无边框窗口最小验证](08-window-validation.md)、[09: 图片解码与内存最小验证](09-decode-memory-validation.md)。

**Status:** needs-info

## Acceptance criteria

- [x] 两项前置票均有真实通过结果；解码的峰值上限和 Limits 阈值已由用户确认，不能只看原决定票的 resolved 状态开始正式实现。
- [x] 在同一个可运行相框中完成文件夹选择、递归扫描、后台加载与显示。工程的最小构建和应用行为测试入口随此纵向能力落地，不单独交付空骨架。
- [x] 首次无配置只引导选择一次；取消后显示空状态和「右键选择文件夹」提示，不反复弹窗。菜单可重新选择文件夹，并提供明确退出命令。
- [x] 扫描只枚举图片路径，不全量解码。扩展名大小写不敏感，支持 jpg、jpeg、png、webp、bmp；GIF 显示第一帧，不实现动图播放。
- [x] 中文、空格和特殊字符路径可被扫描、加载、保存和再次恢复。空文件夹或无效目录进入空状态，界面不崩溃、不忙循环。
- [x] 当前候选图读取失败、损坏、伪装扩展名或超限时，记录路径，超限另记原因，并寻找下一张可显示图；全无可用图片时保持可操作的无图状态。
- [x] 窗口默认 480×320，首次位于屏幕右下角内缩 24px；无标题栏和系统边框，默认不置顶、不抢焦点，可拖动和八方向缩放，最小尺寸 120×120 逻辑尺寸。
- [x] 适应模式完整显示横图和竖图且不变形，留白默认纯黑，内边距不超过 4px；不做 Stretch、宽边框或视觉装饰。
- [x] 启用 per-monitor DPI 感知，显示数据按所在屏幕的窗口物理像素需求缩放；文件读取、解码和缩放不阻塞 UI，沿用已确认限制，及时释放整图数据。
- [x] 按父规格的配置契约保存文件夹与合法默认设置，合法手改值不被无关保存抹掉；三项 P1 保留键不驱动行为。此票不提前实现本轮进度与历史的跨启动恢复。

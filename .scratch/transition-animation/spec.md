# 切换动画：6 种个性化转场（卷页 / 百叶帘 / 墨晕 / 抽卡 / 像素故障 / 淡化）

用户 2026-11-22 决定（原型评审 + 三轮 grill 共识）：现行「无动画即时切换」（2026-11-22 对齐，提交 `7861e5f`）被本专题取代。原型 `prototype.html`（本目录）评审时 5 个变体全部获用户认可、无一淘汰，故全部落地为可选的切换动画。一手参考：同目录 `prototype.html`。

## 1. 设置与取值

- 设置项「切换动画」共 8 档：无 / 卷页 / 百叶帘 / 墨晕 / 抽卡 / 像素故障 / 淡化 / 随机。**默认卷页**。（淡化为 2026-11-23 收编合并新增，见文末合并注记。）
- 只进**设置窗的播放组**（与播放模式、间隔秒数同组）；相框右键菜单与托盘菜单不加此项（菜单瘦身口径不变）。
- 设置即时生效、落盘、不重启；动画进行中改设置，当前一条播完，新设置自下一次切换生效。
- 复用现有 `animation` 配置键（现为只保存不驱动的 P1 占位，枚举 `Slide/Fade/None`），转正为驱动行为。新枚举存英文键名：`none / curl / blinds / ink / card / pixel / fade / random`，设置窗显示中文。
- 旧值迁移：`none` → 无（保留）；`fade` → 淡化（2026-11-23 收编：该值在对方两档时代是真实行为交叉淡化，映射到新 Fade 档）；`slide` → 默认卷页（从未在我们的体系驱动过真实行为，不做逐项映射）；无法识别的值 → 默认卷页。

## 2. 六种动画（细部参数冻结，不留实现自由发挥）

| 动画 | 键名 | 时长 | 方向 | 细部 |
|---|---|---|---|---|
| 卷页 | `curl` | 550ms | 有 | 新图自导航方向一侧卷入，卷边带一道亮影；旧图同步轻微变暗 |
| 百叶帘 | `blinds` | 650ms | 无 | 8 条竖帘、上沿翻下、自左至右错峰；两个方向同序 |
| 墨晕 | `ink` | 750ms | 无 | 新图以画面中心为圆心圆形扩散晕开（扇形 Mesh 单纹理实现）；旧图同步去色——egui 0.37 tint 为乘法、做不出真去色，用户 2026-11-22 批准近似：旧图盖渐强灰纱 + 压暗，实机清单单独目检此条 |
| 抽卡 | `card` | 600ms | 有 | 绕竖轴翻转：旧图翻走、新图翻正 |
| 像素故障 | `pixel` | 550ms | 无 | 开头约 120ms 旧图错位抖动；新图以 12×8 块随机顺序拼齐 |
| 淡化 | `fade` | 240ms | 无 | 新旧图 alpha 交叉：旧图垫底满幅不动，新图按三次缓出进度叠加（收编自对方交叉淡化，时长沿用其原值） |

- 无音效、无原型之外的粒子/装饰。
- 「无」档即现行即时切换行为，同时是晕动画用户的逃生口；不接系统「减少动态效果」设置。

## 3. 随机模式

- 池 = 6 种动画（含收编的淡化），等概率；**禁止连续重复**（与上一次实际播放的动画不同）。
- 「上一次用了哪种」只存内存、不落盘；重启后首抽无约束。
- 抽到哪种就用哪种自己的时长与方向规则。

## 4. 方向语义

- 只有卷页、抽卡分方向：下一张与上一张的入场侧/翻转方向相反，方向在产生导航候选时由导航意图定死，不因加载完成顺序反转（继承工单 14 口径）。
- 百叶帘、墨晕、像素故障、淡化不分方向：上一张/下一张播放完全相同的动画，不做镜像等假方向。

## 5. 触发范围

- 手动切换与自动轮播共用同一动画，不搞两套。
- 首图不播（无旧图可过渡，直接落位）；换文件夹/重扫后的第一张不播（同理）。
- 设置窗内改选项不播预览动画。

## 6. 不变量（继承工单 14，全部继续成立）

- 目标图**解码就绪后才开始**动画；未就绪时保留当前图，不闪白；加载在后台，不阻塞拖动与 UI。
- 动画期间的新切换意图**只保留最后一个**，不并行动画、不按点击次数累积；当前动画结束后处理保留的意图。
- **提交点在动画完成时**：记账、历史、落盘、从完成时刻重计轮播间隔，都只在动画完成时发生；失败/失效目标不提交、不更新当前图与历史。
- 动画期间新旧两张纹理可共存，完成后立即释放旧图纹理；长期只留当前图与下一张显示数据，稳态工作集口径（≤80MB）不因动画上涨。
- 动画期间暂停：当前一条播完并提交，但不再起新的轮播计时。
- 相框隐藏/不可见时切图不播动画，直接提交。

## 7. 几何与画面

- 新旧图宽高比不同时：**动画开始瞬间先把窗口变到新图比例**（既定「先调尺寸再切图」先例，工单 06），再在新舞台内播动画；窗口尺寸本身不做平滑动画。
- 动画期间旧图按自身比例居中绘制、**绝不拉伸**；边缘短暂露底可接受。
- 动画只发生在图片区域内：框体、卡纸、自定义相框图、异形轮廓全程不动；窗口位置锚点沿用普通切图的既有几何规则，动画不新增锚点逻辑。

## 8. 性能护栏（验收线）

- 动画按**墙钟时长**推进：掉帧时跳进度、不延长总时长。
- 百叶帘的条、像素故障的块必须是**同一张纹理的子区域（UV）绘制**，禁止生成多张纹理。
- 动画期间宿主才连续重绘；动画结束立即回到静止零重绘。

## 9. 术语

- GLOSSARY 词条「动画类型」更名为「**切换动画**」：切换时新旧画面的过渡方式——无、卷页、百叶帘、墨晕、抽卡、像素故障、淡化，或随机；_Avoid_：转场、过渡动画。（由工单 04 落地，淡化由收编工单 05 补入。）

# 02: 宿主渲染·有方向组（卷页 + 抽卡）

**What to build:** 宿主按核心转场事件渲染两种有方向动画：卷页（curl，550ms，新图自导航方向一侧卷入、卷边带亮影、旧图轻微变暗）与抽卡（card，600ms，绕竖轴翻转、旧图翻走新图翻正）。方向来自核心事件，宿主不自判方向。

**Blocked by:** [01: 配置转正与核心转场状态机](01-config-and-core-transition.md)

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 卷页：下一张自右侧卷入、上一张自左侧卷入；卷边有一道亮影；旧图在动画期间轻微变暗；结束时画面与无动画直落的最终状态一致。
- [ ] 抽卡：绕竖轴翻转（非横轴）；下一张/上一张翻转方向相反；新图翻正落位后无残余变换。
- [ ] 几何口径：动画开始帧窗口已变到新图比例（核心/几何既有路径负责），宿主在新舞台内绘制；旧图按自身比例居中、绝不拉伸；动画只动图片区域，框体/卡纸/相框图/异形轮廓不动。
- [ ] 墙钟推进：按事件给定的时长以墙钟计算进度，掉帧跳进度不延长；结束帧回送转场完成回执（01 的接缝），不提前也不拖延一帧以上地漏发。
- [ ] 双纹理共存仅限动画期间；完成回执后旧纹理随既有替换路径释放，不新增常驻纹理。
- [ ] 动画期间宿主连续重绘，结束后立即回到静止零重绘（沿用宿主帧尾唤醒裁决，不另起计时器）。
- [ ] Windows 目标 check/clippy 通过；实机目检项并入工单 04 的实机清单（本票状态置 needs-info 待回执）。

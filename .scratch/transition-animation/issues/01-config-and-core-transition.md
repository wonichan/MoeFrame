# 01: 配置转正与核心转场状态机

**What to build:** 把只保存不驱动的 `animation` 配置键转正为 7 档切换动画（无/卷页/百叶帘/墨晕/抽卡/像素故障/随机，默认卷页）；核心层恢复并泛化转场状态机——动画种类与方向在导航意图产生时定死、随机抽法（等概率、禁连续重复、只存内存）、提交点在转场完成、动画期间只留最后一个意图、隐藏时直落。宿主渲染不在本票（02/03），本票的转场以「宿主按墙钟时长回送完成」为接缝。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

## Acceptance criteria

- [ ] `Animation` 枚举改为 7 档，存盘键名 `none/curl/blinds/ink/card/pixel/random`；旧值迁移：`none` 保留，`slide/fade`/未知值落默认卷页；配置往返与迁移有测试。
- [ ] 每档动画的时长在核心层定死：curl 550ms / blinds 650ms / ink 750ms / card 600ms / pixel 550ms；`none` 无转场、即时提交（现行行为不变）。
- [ ] 转场开始事件携带动画种类、方向与时长：方向由导航意图定死，不因加载完成顺序反转；随机档在转场开始时抽定具体动画（等概率、与上一次实际播放不同，只存内存不落盘），随机结果对宿主是具体动画而非「随机」。
- [ ] 提交点在转场完成：记账、历史、落盘、重计轮播间隔只在完成回执后发生；转场期间 Tick 挂起；转场期间暂停仍完成并提交但不计时（继承工单 14 行为测试口径）。
- [ ] 动画/加载期间的新意图只保留最后一个，不并行、不累积；失败/失效目标不启动转场、不提交。
- [ ] 首图与重扫首图不启动转场、直接提交；相框隐藏时切图不启动转场、直接提交。
- [ ] 目标未就绪时不启动转场、保留当前图（不闪白的接缝在核心层成立：转场只在加载成功后产生）。
- [ ] 通过应用行为入口控制时间与加载结果做测试：五种动画的种类/方向/时长、随机不连续重复、连点只留最后意图、慢图、失败、暂停、隐藏直落、首图直落；不绑定 GUI 帧数或线程调度。
- [ ] 全量测试绿、`scripts/check.sh` 通过；实施笔记落盘。

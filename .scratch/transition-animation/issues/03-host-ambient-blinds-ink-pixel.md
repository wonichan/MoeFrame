# 03: 宿主渲染·无方向组（百叶帘 + 墨晕 + 像素故障）

**What to build:** 宿主按核心转场事件渲染三种无方向动画：百叶帘（blinds，650ms，8 条竖帘上沿翻下、自左至右错峰）、墨晕（ink，750ms，新图以画面中心为圆心圆形扩散、旧图同步去色）、像素故障（pixel，550ms，开头约 120ms 旧图错位抖动、新图 12×8 块随机拼齐）。上一张/下一张播放完全相同，不做镜像假方向。

**Blocked by:** [01: 配置转正与核心转场状态机](01-config-and-core-transition.md)

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 百叶帘：恰 8 条竖帘，自左至右错峰、上沿翻下；帘条为同一张新图纹理的子区域（UV）绘制，禁止生成多张纹理。
- [ ] 墨晕：扩散圆心在画面中心，进度为圆形裁剪扩散；旧图随进度同步去色；结束时无残余裁剪/滤镜状态。
- [ ] 像素故障：抖动只发生在开头约 120ms 且只作用于旧图；新图按 12×8 网格块随机顺序拼齐，块为同一纹理的子区域绘制；随机顺序每条动画重新洗，不要求可复现。
- [ ] 三种动画对上一张/下一张完全一致（无方向分支代码）。
- [ ] 几何与舞台口径同工单 02：新比例舞台、旧图居中不拉伸、只动图片区域、框与轮廓不动。
- [ ] 墙钟推进、完成回执、双纹理上限、动画后回到零重绘，同工单 02 口径。
- [ ] Windows 目标 check/clippy 通过；实机目检项并入工单 04 的实机清单（本票状态置 needs-info 待回执）。

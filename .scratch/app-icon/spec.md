# 应用图标

## 问题

程序没有自己的图标：exe 在资源管理器里是 Windows 默认 exe 图标，
窗口（Alt+Tab 列表）无图标，托盘用的是工单 17 时期的 48×48 占位图
（红框白底小风景）。

## 方案

一套母图、三处落点（用户 2026-11-22 选定 K6「少女侧颜」：粉色蝴蝶结
相框 + 框内黑长直红丝带少女侧颜插画）：

- 母图 `assets/icon.png`（512×512）与多尺寸 `assets/icon.ico`
  （16/20/24/32/40/48/64/128/256）入库。
- exe 文件图标：`build.rs` 仅在 Windows 宿主上用 winresource 把
  icon.ico 编入资源；失败只警告不中断构建。
- 窗口图标：主视口与设置视口都 `with_icon` 同一母图（托盘-only 后
  主要供 Alt+Tab 列表识别）。
- 托盘图标：`assets/tray-icon.png` 换成母图的 48×48 渲染，文件名与
  加载代码不变。

## 不做

- 不做多套主题图标、不做播放/暂停状态变体托盘图。

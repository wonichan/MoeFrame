# 02: 实例发现与松手吸附（枚举校验 / 接触派生 / 贴合与对齐 / 工作区边缘）

**What to build:** 让一扇相框在拖动松手瞬间能吸附到伙伴相框或工作区边缘：进程能用 Win32 按标题 `MoeFrame` 枚举并校验出其他实例的相框窗口、读其矩形；吸附关系按几何接触实时派生（不落盘）；松手时按 12px 阈值计算边对边贴合与同名边对齐目标，经既有几何命令通道落位。拖动全程不干预。本票只做「松手吸附」本身，不做组联动跟随（工单 03）。

**Blocked by:** [01: 实例身份与配置隔离](01-instance-identity-config.md)

**Status:** ready-for-agent

## Acceptance criteria

代码项：

- [ ] 实例发现：枚举标题为 `MoeFrame` 的窗口并做进程校验，只认同类相框窗；自家设置窗（标题不同）、其他程序的同名窗口、已退出实例的残留窗口都不入列。发现逻辑为可单测的纯判定 + 薄宿主枚举层，判定部分有测试覆盖（含「同标题异进程」「设置窗混入」用例）。
- [ ] 接触派生：给定一组窗口矩形与所在屏信息，纯函数派生贴合关系——同屏、相对边间隙 ≈ 0 判贴合，贴合边连通分量即吸附组；间隙大于派生容差不判贴合，跨屏不判贴合。用例覆盖：单边贴合、链式三窗、L 形两边贴合、无接触空集。
- [ ] 松手贴合：拖动结束后对被拖窗做一次吸附计算——相对边距离 ≤12 逻辑 px 时给出间隙归零的目标位置；同名边距离 ≤12px 时给出对齐目标；两类目标同时命中时的优先级在实现中定死并有测试（推荐：贴合优先于对齐）。拖动进行中不发任何吸附相关命令（沿几何机手势口径）。
- [ ] 工作区边缘吸附：被拖窗任一边与所在屏工作区边缘距离 ≤12px 时贴合到边缘（间隙归零，不保留 6px——注意与工单 06 钳制边距区分：吸附是主动贴合到边，钳制的 6px 是溢出平移的保留距离，两条路径不互相改口径）。
- [ ] 落位通道：吸附目标经既有 `GeomCommand` 位置命令落位，不新开第二条窗口移动通道；落位后的位置按既有观察/防抖机制正常落盘（工单 01 的实例段）。
- [ ] 开关生效：全局「窗口吸附」开关关闭时，松手不做任何吸附计算与落位（开关本身的设置窗 UI 与落盘随本票或工单 04 落地均可，但判定逻辑必须读它）；开关状态默认开。
- [ ] `scripts/check.sh` 通过（口径同工单 01：跑不了时用替代口径如实记录，不冒充）。

实机项（汇总进工单 04 的实机清单）：

- [ ] 实机：双开相框，拖一扇靠近另一扇的左/右/上/下边，松手即贴合、间隙为零；拖离超过阈值松手不吸附。
- [ ] 实机：拖一扇靠近另一扇，顶边/底边接近时松手对齐成线。
- [ ] 实机：拖相框靠近屏幕工作区四边，松手贴边。
- [ ] 实机：关掉吸附开关后重复以上操作，均不吸附。

## Context

专题 spec：[多实例吸附](../spec.md) 第 3、5、7、9 节；路线取舍见 ADR-0004。现状事实：产品代码无任何窗口枚举调用（`EnumWindows`/`GetWindowRect` 在 `src/` 零命中，仅独立验证工具对自家窗口用过）；自有 HWND 提取通路已有；几何机在 `pointer_down` 时只记名义值不发命令，松手帧有既有的「松手重校正」时机可挂吸附判定。相框标题固定 `MoeFrame`、设置窗标题不同，是枚举过滤的第一层；进程校验（窗口所属进程的 exe 与自身一致）是第二层，两层都要。

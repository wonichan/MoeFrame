# 03: 组联动跟随与拆组（轮询跟随 / 锚边变尺寸 / Shift 拆组与菜单脱离 / 跨屏脱组）

**What to build:** 让贴合的相框真正成为吸附组：任一实例进程轮询伙伴窗口位置，发现组员移动时按贴合偏移跟随移动自己，实现「拖一扇、整组动」；组员切图变尺寸时以吸附边为锚、邻居不动；Shift+拖动与右键菜单两条拆组路径；跨屏时自然脱组。本票依赖工单 02 的实例发现与接触派生。

**Blocked by:** [02: 实例发现与松手吸附](02-window-discovery-snap.md)

**Status:** ready-for-agent

## Acceptance criteria

代码项：

- [ ] 轮询跟随：每实例按约一帧量级的节奏轮询伙伴窗口矩形；按接触派生（工单 02）确认同组关系后，组员位置变化时本窗按「本窗与组员的贴合偏移保持不变」计算目标并经既有几何命令通道移动；组员未动时不发任何位置命令。跟随计算为纯函数且有测试（单邻居跟随、链式组中间成员、本窗不在组内不跟随）。
- [ ] 静止零打扰：桌面静止（无组员移动、无本窗拖动）时跟随轮询不产生位置命令、不触发持续重绘；各实例回到既有静止零重绘口径。轮询本身的唤醒节奏不得把宿主帧尾唤醒裁决顶成常开。
- [ ] 锚边变尺寸：组内成员因切图（含自动轮播）变尺寸时，以与邻居共享的吸附边为锚——共享边位置不变、向空闲方向变尺寸，邻居不移动；变后共享边仍重合则贴合保留，不再重合则该边贴合在派生中自然消失。多边贴合（一扇同时贴两扇）时锚边选择规则在实现中定死并有测试。用例至少覆盖：右贴合向左长、左贴合向右长、贴合边因缩尺寸脱开。
- [ ] 与工单 06 叠加：锚边变尺寸后溢出工作区的，按工单 06 既有规则平移（先锚边、后钳制），工单 06 的测试不回归、口径不改。
- [ ] Shift 拆组：按住 Shift 拖动组内一扇时，该扇独自移动、不带动组员，且被拖过程中其余组员不跟随它；松手后它与原组的贴合按新位置重新派生（已拉开则脱组，仍贴着则仍在组内——以几何为准，不存「已脱离」标记）。
- [ ] 菜单脱离：相框右键菜单新增「脱离吸附组」一项；点击后本扇与当前组员的联动解除——实现上把本扇平移一个足够脱离接触派生容差的最小距离还是仅标记不跟随，由实现按 spec 第 4 节「脱离后位置不变、后续不联动」口径选定并在 Comments 写明理由；菜单其余项与顺序（菜单瘦身口径）不被破坏，无贴合时该项不出现或置灰（实现定死其一并注明）。
- [ ] 跨屏脱组：组员被拖到另一显示器后，原组留在本屏的成员跟随到屏边被各自工作区钳制停住，不跨屏发位置命令；跨屏者与原组在派生中自然脱开。用例以多工作区矩形构造单测覆盖判定层，实机另验。
- [ ] 吸附开关关闭时：跟随整体停摆，已贴合窗口拖动互不带动（与工单 02 的开关判定共用同一开关值，不另设）。
- [ ] `scripts/check.sh` 通过（口径同前票：跑不了时用替代口径如实记录，不冒充）。

实机项（汇总进工单 04 的实机清单）：

- [ ] 实机：三扇相框链式贴合，拖任意一扇，整组同移且贴合不散；跟随延迟在可接受范围（无明显拖影式滞后或抖动）。
- [ ] 实机：组内一扇开自动轮播切图变尺寸，共享边不动、邻居不被推走；尺寸变化脱开的那条边不再联动。
- [ ] 实机：Shift 拖动组内一扇，独自离开，原组其余成员不动且仍互相联动。
- [ ] 实机：右键「脱离吸附组」后拖动它或拖动原组，两边互不带动。
- [ ] 实机（双屏环境）：把组员拖向另一块屏，原组成员停在屏边不跟过去；跨屏的相框在新屏可重新吸附。

## Context

专题 spec：[多实例吸附](../spec.md) 第 4、5、7、8 节；路线取舍见 ADR-0004。关键约束：联动不建 IPC——每个进程只掌握「自己的窗口 + 枚举到的伙伴矩形 + 接触派生」，跟随是各自算各自的，没有中心协调者；实现时要防两扇同时跟随对方造成的振荡（例如只跟随「正在被拖动/刚移动」的成员、静止成员不反向牵引，规则在实现中定死并写进测试）。菜单脱离与 spec 的张力点在验收第 6 条已注明：spec 定案「脱离后位置不变、只是不再联动」，而接触派生是纯几何的——若实现选「仅标记不跟随」，标记存哪、何时失效（重启？重新贴合？）必须在 Comments 里给出与 spec 不冲突的解释；选「最小平移脱开」则要说明它与「位置不变」的出入并回 spec 补注记。二选一，不许含糊落地。

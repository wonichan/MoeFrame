# 06: 双解码交叉等价测试

**What to build:** 在合流之前，先用一组交叉等价测试把两条解码管线（产品 loading 与工单 09 验证 decode_validation）的行为差异钉死：哪些是等价面、哪些是已知差异，白纸黑字由测试守住，合流（工单 07）与发布门（v1-exe 工单 22/23）都站在这组测试上。

**Blocked by:** None (can start immediately)，但须在 v1-exe 工单 22/23 发布门之前完成。

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 新增交叉等价测试：同一组样本集（覆盖各支持格式、超限尺寸、填充裁剪边界、损坏文件）在多种 Limits 下，分别经产品管线与验证管线加载，断言输出尺寸与拒绝/接受结果一致。
- [ ] fit/fill 尺寸计算的三份实现（两处解码侧整数版 + display 绘制侧浮点版）在测试中互相校验，取整差异如有，逐项列明归类。
- [ ] 已知差异单独成列、不算等价失败：首项为 encoded 字节预检（验证接缝按编码长度预检拒绝、产品按解码输出判定），测试以「差异存在且形态如此」的方式记录它，而不是断言一致。
- [ ] 本票只加测试与差异清单，不改任何一侧实现；若测试暴露清单之外的未知差异，停下记录并上报，不在本票顺手修。
- [ ] 差异清单落到工单 07 的票面输入与发布门的复测说明里（在本票 Comments 中给出清单全文）。
- [ ] 全量测试绿（含新增交叉测试）；双轴 code-review 通过；本票不写实施笔记（纯测试增补，如实测出新差异则按笔记规则另记）。

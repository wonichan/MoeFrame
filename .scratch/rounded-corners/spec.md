## Problem Statement

内置画框的四个角全是直角：框体外沿、框体内沿、卡纸内沿三层边界在角部都以
直角相交。框体截面明暗重做之后，边部的质感已经立体，但角部仍是生硬的直角
拼接，整框看起来「死板」，与真实木质画框角部经打磨略带圆润的观感不符。用户
希望相框的角圆润下来。

## Solution

内置画框的三个角边界全部改为圆角：窗口外沿、框体内沿（即卡纸外沿）、卡纸
内沿（即画面边缘），各自独立的固定半径（20 / 10 / 12 逻辑 px）。框体的截面
明暗、唇线、凹槽、木纹，以及框→卡纸投影、卡纸斜切面、卡纸→画面细影全部沿
圆弧连续绕过角部，不留平色补丁。插画照旧按矩形解码与绘制，卡纸的圆弧内沿
压住插画角尖几像素，视觉上画面四角呈圆角，本体不裁剪。

本次改造只动内置画框的绘制层：内距、窗口几何、解码目标、缩放带与一切命中
口径零改动；极简外观与自定义相框图不受影响；不新增任何设置项。

## User Stories

1. As a 相框用户， I want 内置画框的外角是圆的， so that 相框摆在桌面上不再有生硬的直角感。
2. As a 相框用户， I want 卡纸贴着画面的内沿也是圆的， so that 视线落到画面边缘时圆润感是完整的，而不是只圆了外面一圈。
3. As a 相框用户， I want 插画的四个角在视觉上呈圆角展示， so that 画面与画框的过渡柔和。
4. As a 相框用户， I want 圆角只是卡纸圆弧压住插画角尖几像素、插画本体不被裁剪， so that 「插画完整显示、绝不裁切」的口径不被破坏。
5. As a 相框用户， I want 框体的截面明暗（外暗→内亮→凹槽→唇线高光）在角部沿圆弧连续， so that 角部看起来是整根框料弯过来的，而不是两根直料拼贴。
6. As a 相框用户， I want 胡桃木与原木预设的木纹在角部同样沿圆弧走向， so that 角部质感与边部一致。
7. As a 相框用户， I want 框→卡纸的贴边投影在角部沿卡纸外沿的圆弧连续， so that 投影不出现断点或直角折角。
8. As a 相框用户， I want 卡纸的斜切面（近白切边）与卡纸→画面的细影沿画面边缘的圆弧连续， so that 画面四角的光影是连贯的。
9. As a 相框用户， I want 框体外沿内侧的自绘软阴影沿外角圆弧走， so that 外角透出桌面时阴影不缺角。
10. As a 相框用户， I want 外角圆弧之外透出桌面（窗口本就是透明创建）， so that 圆角是真圆角而不是拿底色填假。
11. As a 相框用户， I want 四款框体预设（胡桃木 / 原木 / 黑 / 白）都同样圆角， so that 换预设不改变圆角口径。
12. As a 相框用户， I want 把卡纸宽拉到 0 时画面边缘仍有圆角（直接由框体内沿呈现）， so that 纯框体形态下圆润感不丢。
13. As a 相框用户， I want 把框宽拉到 0 时外角圆弧落在卡纸外沿上， so that 纯卡纸形态下外形仍然圆润。
14. As a 相框用户， I want 框宽或卡纸宽拉得很小时圆角自动变小而不是画出自交的弧， so that 滑杆任何位置下相框都不穿帮。
15. As a 相框用户， I want 圆角不改变窗口大小、高度口径与图片缩放， so that 升级后我摆好的相框位置尺寸分毫不动。
16. As a 相框用户， I want 圆角后拖动、8px 缩放带、右键菜单等一切操作与之前完全一致， so that 圆角只是好看，不改变使用习惯。
17. As a 相框用户， I want 图库为空时框体照常呈现且四角圆润、提示文字仍浮在洞中央， so that 空状态与正常状态外观一致。
18. As a 相框用户， I want 自定义相框图失效回退到内置默认画框时回退框同样带圆角， so that 回退形态与内置形态观感统一。
19. As a 相框用户， I want 极简外观保持原来的直角贴边样子， so that 喜欢 V1 原貌的人不受影响。
20. As a 创作者用户， I want 自定义相框图的角完全由我画的图决定、程序不做任何圆角处理， so that 相框图的创作自由不受限。
21. As a 相框用户， I want 圆角不出现在设置窗里（没有新滑杆、新开关）， so that 设置保持现在的简洁，圆角是所有人一致的默认观感。
22. As a 维护者， I want 圆角半径是代码里的固定常量（与截面 PROFILE_STOPS 同级）， so that 真机观感不合意时改常量即可，不引入配置面。

## Implementation Decisions

- **范围**：仅内置画框绘制层。极简外观的绘制路径、自定义相框图的分析与
  九宫格绘制路径均不触碰。回退内置默认画框走内置绘制路径，天然带圆角。
- **三个角边界与半径**（逻辑 px，固定常量，不入配置、无设置项）：
  - 窗口外沿（框体外沿；框宽 = 0 时为卡纸外沿）：20
  - 框体内沿（即卡纸外沿；框宽 = 0 时该边界不存在）：10
  - 卡纸内沿（即画面边缘；卡纸宽 = 0 时该边界即框体内沿）：12
- **夹紧规则**：每个边界的实际半径 = min(定值， 该边界所在带在该边的厚度）；
  厚度为 0 的带不产生边界。卡纸宽 = 0 时画面边缘半径取卡纸内沿定值 12（由
  框体带夹紧）；框宽 = 0 时外沿半径 20 由卡纸带夹紧。半径还不得超过窗口
  半宽 / 半高的较小者（极小窗口下由布局接缝统一夹紧）。
- **内角覆盖式**：插画的解码目标与绘制矩形不变；卡纸层（含其圆弧内沿）按
  现有绘制顺序压住插画角部。被覆盖的仅是半径 12 的角尖区域，插画像素数据
  不裁剪。FR-312 修订时补明「内沿圆角覆盖角部不在裁切之列」。
- **布局接缝（沿用既有接缝，不新增）**：库层布局模块继续以纯数据输出内置
  画框的全部绘制要素；在现有层矩形与明暗带数据之上，每个角边界补出四角的
  圆心与实际半径（夹紧后），明暗带、投影带、斜切面等带状要素在角部以弧段
  形式给出。宿主绘制层只按数据作画（圆角填充、弧线描边、弧带填充），不做
  任何半径推导。
- **质感沿弧连续**：截面 12 条插值带、唇线、凹槽线、木纹条纹、框→卡纸投影
  衰减带、卡纸斜切面环、卡纸→画面细影衰减带、框体外沿内侧软阴影带，在角
  部全部以与直边相同的参数沿圆弧延续；参数（PROFILE_STOPS、方向光、衰减
  深度与不透明度）不因圆角改变。
- **绘制计划不变**：圆角只在内置绘制臂内可达；极简与自定义臂的绘制计划
  结构性地不含圆角要素（与阴影只在内置臂可达同一手法）。
- **几何与命中零改动**：窗口几何模块的内距、由高度推导宽度的口径、解码目
  标（画面区域物理尺寸）、8px 矩形缩放带、拖动与右键命中区域全部保持现状；
  圆角不进入任何几何计算。
- **文档修订**：FR-311 补圆角口径（三个边界、半径定值、夹紧与退化规则）；
  FR-312 补内沿圆角覆盖的裁切豁免句；README「外观（V2）」节的内置画框条
  目补一句圆角说明。
- **落地形式**：从 main 拉 feature 分支实现，走 PR 合入，不直推 main；版本
  号在合并时再定。

## Testing Decisions

- **只测外部行为**：测试断言布局接缝输出的绘制数据（各角边界的圆心、夹紧
  后半径、弧段要素的存在与连续性），不断言宿主的 egui 调用细节；绘制观感
  本身由真机清单验收（本机 VM 无法上屏核验，与既往各票口径一致）。
- **被测模块**：库层布局模块（内置画框布局 + 明暗数据）。用例覆盖：
  - 默认内距（框 14 + 卡纸 18）下三边界半径为定值 20 / 10 / 12；
  - 卡纸宽 = 0：画面边缘半径为 12（框体带夹紧范围内），无卡纸边界；
  - 框宽 = 0：外沿半径由卡纸带夹紧，框体边界消失；
  - 带厚小于定值（如框 4 + 卡纸 2）：半径按带厚夹紧且不自交；
  - 极小窗口：半径受半宽 / 半高夹紧；
  - 角部弧段要素齐全：截面带、唇线、凹槽、投影、斜切面、细影在四角均有
    弧段对应物，直边要素数量与口径不变。
- **先行测试惯例**：沿用内置画框明暗重做的布局接缝测试（tests 里的
  frame_layout 系列）——先以像素夹具式的数据断言钉住行为，再改实现；宿主
  绘制层不写单测。
- **真机验收**：在既有真机清单文件尾部新开「圆角」独立一节（已全勾的 27
  项不动），验四点：四角圆润无锯齿、外角透桌面正常、内角压图自然、框宽 /
  卡纸宽滑杆拉到 0 与 40 时圆角不穿帮（夹紧生效）。

## Out of Scope

- 极简外观的圆角（其插画贴边，圆角必然裁剪插画角，与 FR-312 口径冲突）。
- 自定义相框图的任何圆角处理（角由图决定；九宫格四角已等比绘制）。
- 圆角半径的设置项（滑杆 / 开关 / 按预设分别定值）。
- 圆角处的点击穿透（透明角区域维持可拖动，与异形相框同一口径）。
- 缩放带与命中区域跟随圆弧（维持矩形 8px 口径）。
- 设置窗、托盘图标等其他窗口 / 界面的圆角。
- 同心圆式半径推导（半径由带宽联动增减）——本期为独立定值 + 夹紧。

## Further Notes

- 原型验证（2026-11-22）：CSS 原型四变体对比（A 直角现状 / B 10·4·6 /
  C 20·10·12 / D 只圆外角 16·0·0），用户选定 **C 更圆润**，本 spec 的半
  径定值已由 grilling 初值（B）修订为 C。原型存于本目录
  `prototype-rounded.html`（feature 分支存档，非产品代码）。

- 半径定值（20 / 10 / 12）与截面参数同级，属可调绘制常量：真机若觉外角不够
  圆或内角压图过多，先改常量再议，不直接升级为设置项。
- 框体角部因三边界半径独立定值，对角线方向的框料厚度略大于直边：默认
  框宽 14、外 20 / 框内 10 时角部对角厚度约 15.7px，仅比直边厚约 1.7px
  （比原型 B 方案的约 3.3px 更均匀）；grilling 时已确认此形态像手工框的
  角部包边，属预期效果而非缺陷。
- 本 spec 对应工单将在 /to-tickets 阶段拆分；预期是一张绘制层工单（布局
  接缝扩圆角数据 + 宿主沿弧作画 + 文档修订 + 真机清单新节），如拆分时发现
  接缝改造与宿主作画耦合过紧，再议是否分两张。

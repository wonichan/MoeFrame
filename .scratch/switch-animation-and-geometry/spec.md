# 切图动画与相框几何稳定规格

**范围：** V2 之后的插画切换体验补强。**状态：** done（2026-11-22
用户实机验收后收口）。来源：用户 2026-11-22 反馈「切图违和」并完成
三轮 grilling；决策记录见
`.agents/notes/implemented/feature/2026-11-22-switch-animation-and-geometry.md`。

## Problem Statement

切图时画面瞬间替换，没有过渡；新插画按固定的相框高度等比缩放，
宽图会把相框撑出屏幕；相框每次切图都以当前显示位置为基准重新定宽，
宽图被屏幕边缘钳住后，中心点越切越偏，多次切换后整只相框离开原位。
设置窗也没有切换动画的选项，用户无法在「无动画」和「交叉淡化」之间
选择。

## Solution

插画切换改为 240ms 三次 ease-out 的交叉淡化，旧图与新图同时存在、
按各自比例 fit 到当前画面区域，不拉伸；窗口尺寸与位置同步做动画，
围绕用户最后一次摆放的**名义中心**推导，而不是围绕被屏幕钳过的当前
显示位置。目标几何越出显示器工作区时，把越界边压到 6px 边距；宽图
导致宽度超过工作区时临时降低显示高度，但只改显示、不写回配置。
设置窗「切换动画」提供「无 / 交叉淡化」两档；旧 `slide` 配置值按交叉
淡化处理，避免迁移默认配置。

## User Stories

1. 作为相框用户，我希望切图时旧图淡出新图淡入，so that 画面不会生硬跳变。
2. 作为相框用户，我希望窗口宽高随新图比例平滑变化，so that 相框像被自然拉伸，而不是瞬移。
3. 作为相框用户，我希望宽图切换后仍完整留在屏幕内，so that 相框不会一半露在屏幕外。
4. 作为相框用户，我希望多次切换横竖图后相框仍停在原来的桌面位置，so that 相框不会越切越偏。
5. 作为相框用户，我希望超宽图临时缩矮后，切回竖图能恢复原来的高度，so that 临时适配不会永久改掉我的设置。
6. 作为相框用户，我希望在设置窗选择「无动画」或「交叉淡化」，so that 我能按自己的喜好控制切换效果。
7. 作为相框用户，我希望动画期间拖动窗口能立即接管，so that 动画不会跟我抢窗口位置。

## Implementation Decisions

- 转场复用 `app_core` 既有的 `StartTransition` / `TransitionCompleted`
  接缝；宿主收到 `StartTransition` 后启动 240ms 交叉淡化，结束时才回送
  `TransitionCompleted`。`animation = "none"` 立即完成；`slide` 与
  `fade` 都按交叉淡化处理；首图加载、重扫后的首图不动画。
- 交叉淡化用两层纹理：旧图保持自身比例 fit 到当前画面区域，新图同样
  fit，逐帧设置透明度；窗口边框随几何动画逐帧重绘。旧图不拉伸。
- 几何动画与淡化共用同一时间轴：窗口尺寸和位置一起插值，位置每帧按
  当前尺寸做工作区钳制，终点让越界边贴住工作区 6px 边距。
- 中心锚定使用 `GeometryMachine.nominal_center`：初值来自存档位置与
  存档尺寸中心，用户拖动时更新；宽图被钳到屏幕边缘不改变名义中心，
  所以切回窄图能回到原中心。无图时观察到的窗口位置也更新名义中心。
- 工作区从窗口句柄 `MonitorFromWindow` + `GetMonitorInfoW` 取
  `rcWork`，物理像素除以 `pixels_per_point` 换成逻辑坐标；取不到时
  退回旧口径。工作区按动画开始时的窗口中心选定，动画中途不换屏。
- 超宽时先按名义高度算宽；超过工作区宽度减 12px 就把显示高度降到
  刚好放下。临时高度只影响当前显示，不进入落盘防抖；配置保存名义
  高度，切回竖图或重启后恢复。
- 动画期间不写几何配置；用户拖动/缩放、右键、关闭等操作立即取消
  几何动画并立即提交这次切换。Windows 原生拖动/缩放进入模态循环时
  指针状态可能丢失，宿主用 `native_gesture_active` 与物理左键状态
  兜底，让几何机按最终位置更新名义中心，避免松手第一帧把窗口拉回。
- 设置窗「切换动画」两档：无写回 `animation = "none"`，交叉淡化写回
  `"fade"`；旧 `slide` 在设置窗显示为交叉淡化，选中它不触发重写。
  时长固定 240ms，不开放配置；`pause_on_hover`、`show_filename`
  仍只保存不驱动行为。

## Testing Decisions

- 库层 `window_geom` 覆盖：尺寸/位置插值、终点无中间尺寸落盘、6px
  工作区钳制、名义中心不漂、临时缩高不落盘、用户拖动中断动画、
  原生拖动丢指针事件后不回旧位置、松手后按新中心校正。共 32 项。
- 会话层 `settings_session` 覆盖切换动画点选的同值守卫与动作顺序；
  配置层 `config` 覆盖动画字段落盘与其余字段保留。共 27 + 30 项。
- 宿主几何校验 `window_validation` 13 项继续通过。
- 真机：用户已逐项验收交叉淡化、窗口尺寸/位置、中心稳定、6px 边距、
  临时缩高、配置落盘、刷新与资源、回归；随后报告「无法拖动」与
  「设置窗没有动画选项」两个回归，修复后确认可用。

## Out of Scope

- 滑动方向、滑动距离、其他缓动或可调时长。
- 逐显示器工作区跟踪与动画中途跨屏重算。
- 启动首图、重扫首图的入场动画。
- `pause_on_hover`、`show_filename` 的行为升格。
- 修改 V2 相框外观、框体绘制或自定义相框图契约。

## 2026-11-23 收编注记（本专题已被取代）

本专题与 `.scratch/transition-animation` 专题（PR #4）在同一时段并行落地、正面冲突。用户 2026-11-23 拍板「以 PR #4 为准」收编，本专题自此被取代，逐项去向：

- **交叉淡化保留**：收编为切换动画体系的新档「淡化」（`fade`，240ms，随机池 6 种之一），存量 `fade` 配置值映射到新档。
- **几何平滑动画被定案否决**：切图尺寸/位置插值、名义中心锚定、切图位置钳制、动画中断命令已撤除；切图几何回到「瞬间变到新图比例、不移动窗口位置」（transition-animation spec §7）。
- **设置两档撤除**：设置窗改用 transition-animation 的播放组 8 档。
- **保留的独立成果**：原生拖动后窗口回弹修复（原生手势旗标 + 指针名义更新与松手重校正）、名义高度与超宽临时缩高不落盘（改为瞬时尺寸适配）、工作区观察通路。

现行口径以 [transition-animation spec](../transition-animation/spec.md) 与其工单 05 为准；本文件与下方工单保留为历史记录，不再驱动实现。

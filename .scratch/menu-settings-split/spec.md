# 菜单与设置窗职责再分工

用户 2026-11-22 决定：相框右键菜单只保留高频播放操作，其余功能全部收进设置窗。

- 相框右键菜单（最终五项，顺序固定）：上一张、下一张、暂停/播放、设置、退出。
- 移入设置窗的：选择文件夹…、当前图三项（打开当前原图、打开所在文件夹、复制图片路径）。
- 设置窗原本就有的保持不变：路径输入框、重新扫描、播放模式、切换间隔（预设 + 自定义秒数）、恢复默认位置与大小、开机自启。
- 托盘菜单不改（本就只有显隐、播放/暂停、上下张、设置、退出，与新分工一致）。
- 首次启动自动弹文件夹选择器不变（不经菜单）；空状态提示文字改指向设置窗。

父规格 `.scratch/v1-exe/spec.md` §6 的菜单构成表述以本决定为准（不改写父规格正文，取代关系记入实施笔记与受影响工单的对齐评论）。

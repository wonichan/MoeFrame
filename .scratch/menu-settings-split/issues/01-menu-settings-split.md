# 01: 右键菜单瘦身与设置窗收编其余功能

**What to build:** 按父规格（本专题 spec.md）的再分工落地：相框右键菜单只剩上一张、下一张、暂停/播放、设置、退出；选择文件夹与当前图三项移入设置窗；设置窗既有内容不变；托盘菜单不改。

**Blocked by:** None (can start immediately)

**Status:** needs-info

## Acceptance criteria

- [x] 相框右键菜单只剩五项且顺序固定：上一张、下一张、暂停/播放（文案随状态）、设置、退出；无分隔线残留、无其他项。
- [x] 设置窗新增「选择文件夹…」按钮：点击打开系统文件夹选择器，选中后走既有换库流程（与原菜单项同一核心意图与效果）；取消选择不改变任何状态。
- [x] 点「选择文件夹…」不提交路径草稿的待结算（与「重新扫描」同规，待结算被丢弃），草稿文字保留；选定新文件夹生效后，路径框按生效值重播种（既有快照作废机制）。
- [x] 设置窗新增「当前图」一组：打开当前原图、打开所在文件夹、复制图片路径，仅在有图显示时出现，作用于当前显示的原图（与原菜单项同一实现与路径口径）。
- [x] 设置窗既有内容（路径输入框、重新扫描、播放模式、切换间隔预设与自定义秒数、恢复默认位置与大小、开机自启）行为不变；托盘菜单不改。
- [x] 空状态提示文字不再写「右键选择文件夹」，改为指向设置窗（如「右键打开设置，选择图库文件夹」）；首次启动自动弹文件夹选择器的行为不变。
- [x] 设置窗尺寸按新增内容调整；新增会话语义（选文件夹丢弃路径待结算）有会话层测试；全量测试绿、Windows 目标 check 通过；双轴 code-review 通过。
- [x] 实施笔记按规则落盘；受影响工单（v1 10/15/18/19、深挖 02）与两份实机清单补对齐记录。

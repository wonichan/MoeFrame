# 02: 内置画框——三层绘制、预设、滑杆与自绘阴影

**What to build:** 内置画框模式下按三层绘制（框体 + 卡纸 + 内沿
细线），框体四款预设（胡桃木默认/原木/黑/白），框宽与卡纸宽
双滑杆（0–40 逻辑 px，卡纸可为 0），窗口外侧自绘软阴影。

**Blocked by:** 01（本专题）

**Status:** needs-info

## Acceptance criteria

- [x] 三层绘制齐全，卡纸默认米白，内沿细线紧贴画面
- [x] 四款预设可切换并持久化，默认胡桃木
- [x] 双滑杆实时生效并持久化；卡纸 = 0 时退化为纯框体
- [x] 自绘软阴影只在内置模式出现，极简/自定义无此阴影
- [x] 内距与工单 01 的几何口径一致（框宽 + 卡纸宽 = 单边内距）
- [x] 布局接缝覆盖三层绘制矩形（库测试：卡纸 = 0 时退化为两层、
      内沿紧贴画面）

## Comments

- 2026-11-22 实现落地（分支 impl/v2-frame-02，功能提交 90263da）：
  新增库模块 `frame_layout` 布局接缝——`builtin_layers` 按窗口
  矩形 + 四边内距 + 框宽产出框体/卡纸/画面三层矩形（画面层与
  几何口径同源），`shadow_layers` 产出阴影扩散层序，宿主只照单
  绘制；内置参数落 `[display]` 三键（`frame_preset` 默认 walnut、
  `frame_width` 默认 14、`mat_width` 默认 18，钳制 0..=40、字段
  级修复同规），`AppearanceMode::insets(frame)` 替换工单 01 的
  内置占位（单边 = 框宽 + 卡纸宽）；设置窗「外观」组内新增内置
  参数块（预设单选 + 双滑杆，仅内置模式显示），经会话机三个新
  动作（同值守卫、顺序在外观之后）由宿主改值并整组写回，滑杆
  逐帧即时生效；绘制在新宿主模块 `frame_paint`（预设色合成 +
  框带同心细线冒充木纹、卡纸米白、内沿 1px 暗线贴画面边界、
  纹理只落画面层），内置模式面板底改透明。实现笔记：

# 02: 内置画框——三层绘制、预设、滑杆与自绘阴影

**What to build:** 内置画框模式下按三层绘制（框体 + 卡纸 + 内沿
细线），框体四款预设（胡桃木默认/原木/黑/白），框宽与卡纸宽
双滑杆（0–40 逻辑 px，卡纸可为 0），窗口外侧自绘软阴影。

**Blocked by:** 01（本专题）

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 三层绘制齐全，卡纸默认米白，内沿细线紧贴画面
- [ ] 四款预设可切换并持久化，默认胡桃木
- [ ] 双滑杆实时生效并持久化；卡纸 = 0 时退化为纯框体
- [ ] 自绘软阴影只在内置模式出现，极简/自定义无此阴影
- [ ] 内距与工单 01 的几何口径一致（框宽 + 卡纸宽 = 单边内距）

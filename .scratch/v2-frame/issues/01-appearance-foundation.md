# 01: 外观地基——透明创建、模式设置与四边内距几何

**What to build:** 相框窗口改为永远透明创建（极简/内置模式自绘
不透明背景，视觉与现状一致）；外观模式（极简/内置/自定义）落
`[display]` 配置并进设置窗「外观」组；几何推导泛化为四边独立
内距（外框 = 画面 + 四边内距，高度 = 外框总高度）；解码口径改
为画面区域物理尺寸。本票只做地基：内置模式先按内距全 0 占位，
极简模式像素级不变。

**Blocked by:** None (can start immediately)（V2 已于 2026-11-22
启动，专题级阻塞解除）

**Status:** needs-info

## Acceptance criteria

- [x] 相框窗口透明创建；极简模式外观、空状态与现状一致
- [x] 外观模式可在设置窗「外观」组切换并持久化，切换不重启
- [x] 几何：给定四边内距与图比例，外框尺寸推导正确（库测试覆盖，
      含四边不等与内距全 0 退化为现状两例）
- [x] 解码口径 = 画面区域尺寸；内距为 0 时与现状等值
- [x] 恢复默认尺寸按外框总高度口径工作
- [ ] 透明创建落地后用既有测量脚本复测稳态工作集与冷启动并记录；
      明显恶化（对照 ≤80MB 预算与 ~0.3s 冷启动基线）要回议 spec，
      不得静默交付

## Comments

- 2026-11-22 实现落地（分支 impl/v2-frame-01，功能提交 190db93）：
  根视口 `with_transparent(true)` 永远透明创建，极简/内置靠中央
  面板铺满视口的不透明填充保持 V1 视觉；外观模式落
  `[display].appearance`（默认 builtin，字段级修复同规），经
  config_sync 宿主状态镜像写回、启动包 HostInit 携带初值；设置窗

  有测试钉住；设置窗高 700→750）；几何机观察输入增加
  `Insets`（四边独立），推导改为画面高 = 外框高 − 上下内距、
  内距变化触发重新推导，恢复默认按外框总高；宿主
  `physical_target` 改为画面区域物理尺寸，显示数据管线接口
  不变。三模式内距本票均为全 0 占位（`AppearanceMode::insets()`，

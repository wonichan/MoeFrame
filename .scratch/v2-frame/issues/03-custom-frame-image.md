# 03: 自定义相框图——九宫格加载、洞自动检测与失效回退

**What to build:** 自定义模式下加载用户 PNG 相框图：自动检测
透明矩形洞（从中心扩展），按九宫格绘制（四角原样、四边沿长度
拉伸），框厚按窗口宽度等比缩放；四边内距来自检测结果（缩放后）。
设置窗提供相框图选择与检测结果/错误显示；文件失效或不符合契约
时回退内置默认画框并在设置窗标出原因。

**Blocked by:** 01（本专题）

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 合规 PNG（中心透明矩形洞）可加载，四边内距检测正确
      （库测试覆盖：标准洞、偏置洞、中心不透明判无效）
- [ ] 窗口比例变化时角部图案不变形（九宫格语义，真机复核）
- [ ] 框厚随窗口宽度等比缩放
- [ ] 相框图路径持久化；文件被删/无效时回退胡桃木内置框，
      设置窗显示原因，程序不白屏不崩溃
- [ ] 非 PNG 或无透明洞的图片被明确拒绝并给出原因

# 04: 异形相框——透明外轮廓与空状态

**What to build:** 自定义相框图的外轮廓可不规则：相框图透明区域
直接透出桌面（窗口已由工单 01 透明创建，本票处理绘制与状态）；
异形模式不带阴影；空状态保留框体、洞透明、提示文字浮在洞中央。
透明区域不做点击穿透（等同框体可拖动），缩放带维持矩形 8px。

**Blocked by:** 03（本专题）

**Status:** needs-info

## Acceptance criteria

- [x] 外轮廓带透明区域的相框图正确显示，透明处透出桌面
- [x] 透明处可拖动窗口；矩形 8px 缩放带行为与其它模式一致
- [x] 异形模式无阴影（内置模式的自绘阴影不出现在此模式）
- [x] 空状态：框体在、洞透明、提示文字居中可读
- [x] 洞仍为矩形，插画完整不裁切

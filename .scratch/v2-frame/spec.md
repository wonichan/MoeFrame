# V2 专题：相框外观（画框）

**范围：V2。** v0.1.0 发布不含本专题；2026-11-22 三轮 grilling 达成
共识后记录于此，V2 启动时按工单实施。术语见根目录 `GLOSSARY.md`
（相框 / 外观 / 画框 / 框体 / 卡纸 / 内距 / 相框图 / 异形相框）。

## 背景

现行相框是无边框裸窗口：图片贴边铺满，连 1px 描边都没有。用户
认为不够美观，希望有真实相框把插画裱起来的观感，并支持用户自己
出图提供相框（含异形）。这与 V1 需求 FR-309（P0：窄边框、禁止
相框式设计）正面冲突——用户 2026-11-22 明确改主意，FR-309 在 V2
被本专题取代（见下「需求变更」）。

## 共识决策（三轮 grilling，2026-11-22）

### 外观模式

1. 外观三选一：**极简**（现状，无画框）/ **内置画框** / **自定义
   相框图**。默认内置画框；极简保留可切回。
2. 设置入口只在设置窗新「外观」组；右键菜单维持五项不动。

### 内置画框

3. 三层结构：**框体 + 卡纸 + 内沿细线**。卡纸默认米白。
4. 框体预设四款：胡桃木（默认）/ 原木 / 纯黑 / 纯白。
5. 框宽、卡纸宽各一个滑杆（0–40 逻辑 px），卡纸可调至 0 禁用；
   默认值框体 14、卡纸 18（480×320 量级，真机再校准）。
6. 阴影：自绘软阴影（多层半透明扩散），不用原生窗口阴影。

### 尺寸口径

7. 设置的高度 = **外框总高度**（所见即所得）；图在框内完整显示、
   永不裁切（铁律不动）。宽度仍由图的比例推导。
8. **内距四边独立建模**（左/右/上/下可不等），内置画框是四边相等
   的特例。几何推导泛化为「外框 = 画面 + 四边内距」；解码口径
   （显示数据目标尺寸）= 画面区域物理尺寸，不再是整个窗口。

### 自定义相框图

9. 契约：**PNG，九宫格**——中间是透明矩形「洞」，四角原样绘制、
   四边只沿长度拉伸，窗口比例变化时角部图案不变形。洞的位置由
   程序**自动检测**（从图片中心向外扩展找全透明矩形；中心不透明
   = 无效图），不提供手动边距数值。
10. 框厚**按窗口宽度等比缩放**（系数 = 窗口宽 ÷ 相框图原宽），
    不给额外滑杆。
11. 配置只存相框图**路径**（与图库文件夹同理），不复制进程序目录。
12. 相框图失效（文件丢失/不符合契约）：**回退内置默认画框
    （胡桃木）**，设置窗在路径旁标出原因，日志记一行；绝不白屏
    或崩溃。

### 异形相框（用户在 Q7 明确要求，不可砍）

13. 相框图的外轮廓可以不规则：透明区域直接透出桌面。异形只存在
    于自定义相框图模式；内置画框恒为矩形。
14. 实现策略：相框窗口**永远以透明方式创建**，极简/内置模式自行
    把背景画成不透明——切模式不重启，视觉与现状一致。
15. **透明区域本期不做点击穿透**：透明处与框体一样可拖动、会挡住
    下面的图标。穿透（按像素命中测试）单独立项，二期再议。
16. 异形模式**本期不带阴影**（按 alpha 轮廓的软阴影留二期）。
17. 缩放带保持矩形 8px（包围盒四边），与内置模式一致，靠光标
    形状给反馈。
18. 空状态（图库为空）：框体保留、洞透明透出桌面、提示文字浮在
    洞中央。
19. **洞恒为矩形**：插画完整不裁切，相框图作者若要异形只能动
    外轮廓。

## 需求变更（V2 生效时写入需求文档）

- **FR-309 改写**：由「窄边框、禁止相框式设计」改为「默认带画框
  的相框式外观；极简贴边为可选外观」。
- 新增条款（编号 V2 定稿时顺延，暂记 FR-31x）：
  - 外观模式三选一与设置入口；
  - 内置画框三层结构、预设、双滑杆、自绘阴影；
  - 高度 = 外框总高度、四边内距、解码口径 = 画面区域；
  - 自定义相框图契约（PNG 九宫格 + 洞自动检测）、等比缩放、
    只存路径、失效回退；
  - 异形相框（透明外轮廓、不穿透、无阴影、矩形缩放带、空状态）。

## 工单

- 01 外观地基：透明创建 + 模式设置 + 四边内距几何 + 解码口径
- 02 内置画框：三层绘制 + 预设 + 滑杆 + 自绘阴影
- 03 自定义相框图：九宫格加载 + 洞检测 + 回退
- 04 异形相框：透明外轮廓 + 空状态

## 不做（二期候选）

- 透明区域点击穿透（按像素命中测试）。
- 异形轮廓软阴影。
- 洞的边距手动数值调整。
- 相框图的管理库（多张收藏/切换）——本期只支持选一张。

# V2 专题规格：相框外观（画框）

**范围：V2。** v0.1.0 不含本专题。状态：ready-for-agent（V2 启动后
生效）。来源：2026-11-22 三轮 grilling 共识（决策过程见
`.agents/notes/proposed/feature/2026-11-22-picture-frame-appearance.md`）。
术语一律用根目录 `GLOSSARY.md` 的口径：相框 / 外观 / 画框 / 框体 /
卡纸 / 内距 / 相框图 / 异形相框。

## Problem Statement

相框现在是一块无边框的裸窗口：插画贴边铺满，没有描边、没有留白，
看起来像一张悬空的图片，不像一个摆在桌面上的相框。我想让它真正
像一个桌面相框——有框体、有裱画的层次，把插画裱起来摆着。另外，
程序自带的框样式总有尽头，我希望能用我自己出的图当相框，包括
外轮廓不规则的异形相框，让桌面布置有更大的发挥空间。

## Solution

相框获得「外观」概念，三选一：极简（现状裸图）、内置画框、
自定义相框图，默认内置画框。内置画框是程序绘制的三层结构
（框体 + 卡纸 + 内沿），带预设、宽度调节和柔和投影，看起来像
一只真正的木质画框。自定义相框图允许用户选一张自己制作的 PNG
作为画框：图中间透明的矩形区域是「洞」，插画从洞里露出来；
外轮廓可以不规则，透明处直接透出桌面，形成异形相框。无论哪种
外观，插画永远完整显示、绝不裁切；设置的高度指整个相框
（含画框）的总高度。

## User Stories

1. As a 相框用户， I want 程序默认就带着画框显示插画， so that 桌面上摆着的像一只真正的相框而不是悬空的图片。
2. As a 相框用户， I want 在设置里把外观切回极简， so that 想清爽的时候还能用原来的贴边裸图样式。
3. As a 相框用户， I want 内置画框有框体、卡纸、内沿三层， so that 它看起来是裱好的画，而不只是一圈粗边。
4. As a 相框用户， I want 在胡桃木、原木、黑、白四款框体预设间切换， so that 框色能配我当前的插画和桌面。
5. As a 相框用户， I want 调节框体宽度， so that 框的粗细合我心意。
6. As a 相框用户， I want 调节卡纸宽度、并能把它调到 0， so that 我能从「美术馆裱法」切到「细框贴画」的现代裱法。
7. As a 相框用户， I want 内置画框带一圈柔和的投影， so that 相框像实物一样立在桌面上。
8. As a 相框用户， I want 我设定的高度就是相框整体的高度， so that 尺寸所见即所得，不用心算框占多少。
9. As a 相框用户， I want 切换插画时相框跟着新图比例自动定宽， so that 每张图都被正好裱住、不留黑边不裁切。
10. As a 相框用户， I want 插画在任何外观下都完整显示， so that 画面内容一点都不会被框吃掉。
11. As a 创作者用户， I want 用我自己画的 PNG 作为相框， so that 相框能带上我自己的图案和角色元素。
12. As a 创作者用户， I want 只需把 PNG 中间留出透明矩形、不用填任何参数， so that 出图的流程简单到只需要会画图。
13. As a 创作者用户， I want 程序自动找到透明洞的位置， so that 洞不必居中、四边不等宽（比如拍立得式宽下边）也能用。
14. As a 创作者用户， I want 相框图四角的图案在窗口比例变化时不被拉变形， so that 我画的缎带和花纹始终是原本的样子。
15. As a 创作者用户， I want 相框的粗细随窗口大小成比例变化， so that 放大缩小都保持我出图时的构图比例。
16. As a 创作者用户， I want 做出外轮廓不规则的异形相框， so that 相框可以有角色探头、花边外形这类自由造型。
17. As a 相框用户， I want 异形相框的透明处直接看到桌面， so that 异形是真的镂空，而不是拿黑色填假。
18. As a 相框用户， I want 抓住异形相框的透明处也能拖动它， so that 造型再怪也不愁没地方下手挪。
19. As a 相框用户， I want 选的相框图不符合要求时被明确告知原因， so that 我知道图该怎么改（比如中心必须是透明的）。
20. As a 相框用户， I want 相框图被我删掉或移动后程序自动用回内置框， so that 相框永远不会白屏或打不开。
21. As a 相框用户， I want 图库为空时相框空着摆在桌面上、洞里透出桌面， so that 空相框也是个好看的桌面物件，而不是一块黑板。
22. As a 相框用户， I want 所有外观设置关掉程序再开都还在， so that 不用每次重新调。
23. As a 相框用户， I want 外观设置只出现在设置窗里， so that 右键菜单保持现在的简洁五项。
24. As a 相框用户， I want 加了画框之后相框依然轻量， so that 常驻内存和流畅度不被外观拖垮。
25. As a 相框用户， I want 拖动和缩放的操作方式在三种外观下都一致， so that 换外观不用重新学。
26. As a 创作者用户， I want 相框图只按我给的路径读取、不被复制得到处都是， so that 我改图后重新打开就是新版。

## Implementation Decisions

- 外观模式三选一（极简 / 内置画框 / 自定义相框图），默认内置
  画框；模式与全部外观参数存入既有 `[display]` 配置域，经既有
  配置同步通道落盘；设置入口只在设置窗新增的「外观」组，右键
  菜单不新增项。
- 相框窗口改为**永远以透明方式创建**；极简与内置模式由绘制层
  自行铺不透明背景，视觉与 V1 一致；切换模式不重启进程。
- 几何泛化：**内距四边独立**（左/右/上/下可不等），外框尺寸 =
  画面尺寸 + 四边内距；高度设置指外框总高度；宽度仍由当前图
  比例推导。几何状态机的观察输入增加四边内距，内距全 0 时行为
  与 V1 逐项一致。恢复默认尺寸按外框总高口径。
- 显示数据口径：解码目标尺寸改为**画面区域**的物理尺寸（不含
  画框），不再按整个窗口；显示数据管线的接口不变，只是宿主喂
  入的目标值变化。
- 内置画框绘制三层：框体（预设四款：胡桃木默认 / 原木 / 黑 /
  白，纯色与简易木纹质感由绘制层合成，不引入图片素材）、卡纸
  （默认米白）、内沿细线（紧贴画面）。框宽、卡纸宽为两个滑杆
  参数（0–40 逻辑 px，卡纸可为 0）；单边内距 = 框宽 + 卡纸宽。
- 阴影：内置模式用绘制层多层半透明扩散做软阴影，不用原生窗口
  阴影；极简无阴影；自定义模式本期无阴影。
- 新增**相框图分析**模块（库层纯逻辑）：输入解码后的像素，
  输出洞矩形与四边内距，或带原因的拒绝。检测规则只有一条：
  从图片中心像素向外扩展，取包含中心的全透明矩形为洞；中心
  不透明即无效。格式限 PNG（须有透明通道）。
- 相框图绘制走**九宫格**：以洞为界把相框图切成九个区域，四角
  按缩放系数等比绘制、四边只沿长度方向拉伸、洞区不绘制（插画
  在下层）。缩放系数 = 窗口内宽 ÷ 相框图原宽；九宫格与内置
  三层的绘制矩形由一个薄布局纯函数统一产出，宿主只照单绘制。
- 相框图只存路径（与图库文件夹同一口径），不复制进程序目录；
  每次启动与每次切换时重新分析。分析失败或文件缺失时**回退
  内置默认画框（胡桃木）**，设置窗在路径旁显示原因，日志记
  一行；回退不改变已保存的外观模式与路径（用户修好图后切回
  自定义即恢复）。
- 异形：相框图的透明像素不做任何填充，透出窗口后方内容；
  透明区域的命中与框体一致（可拖动、本期不穿透）；缩放带维持
  包围盒矩形 8px；空状态时绘制层只画框体与洞中央的提示文字，
  洞保持透明。
- 需求文档变更（V2 生效时落）：FR-309 改写为「默认相框式外观、
  极简为可选」；新增 FR-31x 外观条款组（措辞见 grilling 记录）。
  V2 生效前需求文档不动，保 v0.1.0 验收口径干净。

## Testing Decisions

- 好测试的标准：只测外部行为与决策结果，不绑实现细节；沿用
  本仓一贯的「库层纯逻辑接缝 + 宿主真机清单」分工。
- **几何接缝（现成）**：几何状态机喂「图比例 + 四边内距」观察、
  断言外框尺寸命令。新增覆盖：四边不等、内距全 0 退化为 V1
  行为、恢复默认。先行先例：`window_geom` 既有测试。
- **相框图分析接缝（新增）**：以程序生成的像素夹具喂分析模块，
  断言洞矩形/四边内距/拒绝原因。覆盖：标准居中洞、偏置洞、
  拍立得式宽下边、中心不透明判无效、无透明通道判无效。先行
  先例：`decode_equivalence` 的像素夹具式测试。
- **布局接缝（新增薄纯函数）**：喂窗口矩形 + 内距 + 相框图
  元数据，断言九宫格九个绘制矩形与内置三层矩形。覆盖：四角
  尺寸只随缩放系数变、四边只沿长度伸缩、卡纸为 0 时三层退化
  为两层。先行先例：宿主 `next_frame_delay` 的纯函数回归测试。
- 宿主绘制（透明创建、阴影、九宫格实际上屏、空状态）不设自动
  化接缝：Windows 目标编译 + clippy 干净，并入真机清单逐项
  复核（与 V1 全部宿主行为同一口径）。
- 透明创建对稳态工作集（≤80MB 预算）与冷启动的影响，在工单
  01 落地后用既有测量脚本复测并记录；明显恶化要回议本 spec。

## Out of Scope

- 透明区域点击穿透（按像素命中测试）——二期候选。
- 异形轮廓的软阴影（按 alpha 生成模糊轮廓）——二期候选。
- 洞边距的手动数值调整（本期只有自动检测一条规则）。
- 相框图收藏库 / 多张相框图管理与快速切换（本期只选一张）。
- 内置画框的异形化（内置恒为矩形）。
- 洞的非矩形化与插画遮罩裁切（插画完整不裁切是铁律）。
- V1 范围内的任何行为变更；v0.1.0 发布不等待本专题。

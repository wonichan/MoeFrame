# 托盘-only 化：任务栏无图标，托盘三分支召回

用户 2026-11-22 决定（grill-with-docs 共识）：MoeFrame 是常驻小工具，图标只应出现在系统托盘，不占任务栏。

- 相框主窗与设置窗都不出现任务栏按钮：构建器定死 `with_taskbar(false)`（egui 0.37 现成口，走 `ITaskbarList::DeleteTab`），无运行时开关、不加设置项。
- Alt+Tab 不处理：现成开关只清任务栏；相框显示时仍在 Alt+Tab 名单内，接受。不引入 Win32 工具窗口样式（WS_EX_TOOLWINDOW）。
- 没有任务栏按钮后，托盘成为唯一召回入口，左键改三分支（托盘菜单「显示/关闭相框」不参与：菜单弹出时相框必然失焦，按标签终态执行，见 2026-11-22 注释）：隐藏 → 显示并聚焦；显示但无焦点 → 唤到最前聚焦（不隐藏）；显示且有焦点 → 隐藏。焦点由宿主在点击帧采样 egui 视口焦点喂给核心判定，未知按无焦点处理（只唤回、不误藏）。

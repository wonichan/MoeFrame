# 01: 相框窗口层级菜单

Type: task
Status: claimed
Spec: ../spec.md

## Goal

实现相框右键菜单中的置顶、置底操作，符合父规格的行为与测试约定。

## Acceptance Criteria

- [ ] 现有相框右键菜单提供“置于顶层”和“置于底层”两项，并显示本次运行中请求的层级。
- [ ] 选择置顶、置底分别向根视口发出对应的 `WindowLevel` 命令；从一个层级切换到另一个层级时立即替代原选择。
- [ ] 再次选择当前层级时向根视口发出普通层级命令；不增加第三个普通层级菜单项。
- [ ] 层级选择只保存在当前进程中，应用启动保持普通层级，且不写入配置。
- [ ] 层级操作不改变相框的可见性、窗口位置或尺寸、当前图、播放状态或计时。
- [ ] 现有宿主 UI 回归接缝驱动真实菜单，并通过合成 egui 输入和根视口输出验证置顶、置底、互切、重复选择恢复普通层级及菜单选择状态；测试不复制生产菜单或依赖原生窗口。
- [ ] Windows 实机验收确认置顶可覆盖普通窗口；置底移到当时的 Z 序底端但之后可被其他窗口覆盖；重复选择恢复普通层级；重启后回到普通层级。未执行的环境保持未验证。
- [ ] `bash scripts/check.sh` 全部通过。
